模块 / 场景：集团管控 — 集权分权
工具名称：管控模式选择表
适用场景：总部对子公司“一管就死、一放就乱”时，按业务成熟度选对管控类型，并配套权责清单，拿捏集分寸。
操作步骤 / 方法：
1. **评业务成熟度**：看子公司能力、风险、战略重要度，成熟度低多管、高少管。
2. **选管控类型**：财务型(甩手掌柜)/战略型(抓方向)/运营型(抓过程)三选一。
3. **列权责清单**：人权/财权/事权逐项归属总部 or 子公司，不模糊。
4. **设审批阈值**：金额/风险分级，超阈值才上报，给子公司空间。
5. **季度动态复盘**：成熟度变了，管控类型跟着调，别一成不变。

模板 / 话术（可直接复制）：
```
【管控模式选择表】
子公司：__________  成熟度评级：__________  日期：__________

一、管控类型矩阵
类型 | 总部抓什么 | 子公司自主什么 | 适用
财务型 | 利润结果 | 经营全过程 | 成熟/非核心
战略型 | 方向+关键人 | 执行 | 成长中
运营型 | 过程+标准 | 有限 | 新/高风险

二、权责清单
事项 | 总部 | 子公司 | 审批阈值
人权(负责人) | | | 
财权(预算) | | | 
事权(投资) | | | 

三、动态调整
触发调整的条件：__________  复盘周期：季度
```

注意事项 / 常见坑：
- 一刀切统一管控，成熟子公司被管死、新公司又放羊。
- 权责清单不清，总部子公司互相踩线。
- 定了不放权，运营型管成保姆。
