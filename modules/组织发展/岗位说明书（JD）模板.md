模块 / 场景：岗位管理 — 任职标准
工具名称：岗位说明书（JD）模板
适用场景：招聘“货不对板”、新人入职发现干的不一样、绩效无基准时，用一张 JD 把“岗位目的、职责、要求、KPI”写清楚，让人岗匹配有准绳。
操作步骤 / 方法：
1. **一句话岗位目的**：说明“为什么存在、解决什么问题”，这是 JD 的锚。
2. **动宾写核心职责**：每条以动词开头（设计/推动/协调），避免“参与”“协助”等虚词。
3. **KSAO 分级列要求**：知识/技能/能力/其他，按“必备/优先”分级，别写“精通一切”。
4. **挂钩 KPI**：职责对应可衡量产出，让 JD 与考核同源。
5. **双签发布**：用人部门负责人+HR 共签，作为招聘、转正、绩效的共同基准。

模板 / 话术（可直接复制）：
```
【岗位说明书 JD】
岗位：__________  所属部门：__________  直接上级：__________

一、岗位目的(一句话)
________________________________

1. ________________________________
2. ________________________________
3. ________________________________

三、任职要求(KSAO分级)
维度 | 必备 | 优先
知识(K) | | 
技能(S) | | 
能力(A) | | 
其他(O) | | 

四、挂钩 KPI
指标 | 目标值 | 考核周期
______|________|________

五、双签
用人部门：__________  HR：__________  日期：__________
```

注意事项 / 常见坑：
- 职责写成“参与/协助”虚词，面试无法验证。
- 要求“精通一切”，把人吓跑也招不到。
- 按“现有某人”画像写 JD，变成量身定制而非岗位需要。
