模块 / 场景：协同机制 — 责任分配
工具名称：跨部门协作 RACI 矩阵模板
适用场景：项目开会全员到、散会没人认责、决议石沉大海时，用 RACI 把每个关键活动的“唯一负责人”标出来，终结集体负责=没人负责。
操作步骤 / 方法：
1. **列关键活动**：把跨部门流程拆成具体活动（不是部门），如“需求确认”“上线评审”。
2. **定唯一 A**：每项活动必须有且仅有一个 Accountable（最终负责），多人负责=没人负责。
3. **配 R/C/I**：执行者(R)、需咨询(C)、需知会(I)分别标注，避免“全员都 R”。
4. **冲突检查**：同一人 A 过多或 C 过多要平衡，防止瓶颈。
5. **上墙公示**：RACI 图贴进协作空间，作为扯皮时的裁决依据。

模板 / 话术（可直接复制）：
```
【跨部门 RACI 矩阵】
项目：__________  维护人：__________

活动 \ 角色 | 部门A | 部门B | 部门C
需求确认 | A | C | I
方案设计 | R | A | C
上线评审 | C | R | A

R=执行  A=唯一负责( accountable )  C=需咨询  I=需知会
校验：每项活动 A 是否唯一？____  某人 A 是否过载？____
```

注意事项 / 常见坑：
- 一项多个 A，等于没有负责人。
- 全员都标 R，责任被稀释。
- 画完不上墙不执行，仍是会海。
