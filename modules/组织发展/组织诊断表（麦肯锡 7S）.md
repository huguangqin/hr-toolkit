模块 / 场景：组织健康 — 问题定位
工具名称：组织诊断表（麦肯锡 7S）
适用场景：公司没违规、人也在，就是推不动、战略落不了地时，用 7S 框架照出“硬要素改了、软要素没动”的隐形错位。
操作步骤 / 方法：
1. **填 7S 现状**：战略/结构/制度(硬)与共享价值观/技能/风格/人员(软)逐项正确填写，不粉饰。
2. **找错位缺口**：对比“应有状态”，标出软硬要素打架处（最常见的病根）。
3. **排优先级**：按“影响大+可改”排序，先动高杠杆的缺口。
4. **定责任人**：每个缺口落到人名，避免“组织要改”无人认领。
5. **季度复盘**：7S 是动态体检，每季度重填一次看对齐度变化。

模板 / 话术（可直接复制）：
```

诊断周期：__________  诊断人：__________

要素 | 现状 | 应有状态 | 缺口 | 责任人
战略 Strategy | | | |

制度 Systems | | | | 
共享价值观 Shared Values | | | | 
技能 Skills | | | | 
风格 Style | | | | 
人员 Staff | | | | 

优先级(高杠杆缺口)：__________
复盘节奏：每季度一次
```

注意事项 / 常见坑：
- 只改结构(硬)，忽视共享价值观(软)，组织照样打架。
- 诊断填“应该的”而非“真实的”，照不出病。
- 诊断完不落责任人，报告睡大觉。
