模块 / 场景：变革落地 — 中人先安
工具名称：组织变革管理表
适用场景：新系统/新架构/新制度推行必遭抵制时，先识别相关方处在变革曲线的哪一阶段、再对症沟通，避免“只发通知不改人心”导致变革翻车。
操作步骤 / 方法：
1. **画相关方地图**：列出受影响群体，按“影响力×支持度”分层。
2. **判变革阶段**：对照 Kübler-Ross 曲线（否认-抗拒-探索-承诺）判断每群人当前情绪。
3. **定沟通计划**：抗拒期多一对一、探索期给能力、承诺期给认可，阶段不同打法不同。
4. **给能力与资源**：员工不是不想变，常是不会变，配套培训与工具。
5. **固化机制**：把新行为纳入考核与流程，防止退回旧习惯。


注意事项 / 常见坑：
- 只发全员通知，忽视情绪曲线，抵触堆积。
- 把“不会”当“不愿”，只压不教。
- 变革完不固化，一阵风退回原样。
