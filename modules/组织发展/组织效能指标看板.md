模块 / 场景：组织健康 — 效能度量
工具名称：组织效能指标看板
适用场景：团队扩了产出没涨、“人头”被当“产能”时，用一组效能指标把组织效率量化，用数字揭穿“人多了反而慢”。
操作步骤 / 方法：
1. **算管理幅度**：直接下属数/管理者，过窄费人、过宽失控，取行业基准。
2. **数组织层级**：从一线到 CEO 的层数，层级过深决策慢、信息失真。
3. **测人效**：人效=产出/人头（营收/利润或交付量），分团队对标。
4. **算协同成本**：跨部门会议时长、流程节点数，作为隐性损耗。
5. **定提效动作**：幅度/层级/人效偏离基线时，给出合并、扁平化或授权动作。

模板 / 话术（可直接复制）：
```
【组织效能指标看板】
统计周期：__________  覆盖：__________

指标 | 公式 | 本值 | 行业基线 | 判断
管理幅度 | 下属/管理者 | | 6-10 | 
组织层级 | 一线→CEO层数 | | ≤5 | 
人效 | 营收/人头 | | | 
协同成本 | 会议h/人周 | | | 

偏离动作：幅度过窄→合并 / 层级过深→扁平 / 人效低→授权
```

注意事项 / 常见坑：
- 以“人头数”论产能，人多了效率反而降。
- 层级过深不自知，决策链条长到失真。
- 只看人效不看协同成本，隐性内耗被忽略。
