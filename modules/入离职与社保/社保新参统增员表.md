模块 / 场景：社保实操 — 增员申报
工具名称：社保新参统增员表
适用场景：新员工入职后，在属地社保系统完成新参统与增员，核定缴费基数，避免漏缴、迟缴产生补缴与滞纳金。
操作步骤 / 方法：
1. 确认参保属地与户籍类型（本地/外地/灵活就业）。
2. 收集身份证号、户口性质、参保险种。
3. 按上年月均工资或首月工核定基数。
4. 用工起30日内在系统增员申报。
5. 核对回执，确认到账，留档。

模板 / 话术（可直接复制）：
```
【社保新参统增员表】
员工：____ 身份证：____ 户籍：____ 参保地：____
参保险种：养老✓ 医疗✓ 失业✓ 工伤✓ 生育✓
申报基数：____ (核定依据：首月工资/上年月均)
增员月份：____ 申报日期：____ 经办：____
系统回执号：____ 到账确认：____
```

注意事项 / 常见坑：
- 超30日增员，面临补缴加每日滞纳金。
- 基数按最低而非实际，被稽核补差罚款。
- 险种漏选（尤其工伤），出事公司全赔。
关联工具：入职手续办理清单、社保基数核定表、社保税务稽核自查表
