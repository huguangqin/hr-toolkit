模块 / 场景：用工模式 — 灵活用工
工具名称：灵活用工合规表
适用场景：规范实习、退休返聘、兼职、平台众包等灵活用工的关系认定与保障，避免误判为全日制劳动关系引发赔偿。
操作步骤 / 方法：
1. 明确用工性质（实习/退休/兼职/众包）。
2. 签对应协议而非劳动合同。
3. 退休返聘确认已领养老金、买意外险。
4. 实习生不低于当地最低小时工资。
5. 众包走结算平台，取得合规票据。

模板 / 话术（可直接复制）：
```
【灵活用工合规表】
人员：____ 类型：实习/退休/兼职/众包
协议类型：____ (非劳动合同)
退休已领养老金：✓ 意外险：✓
实习时薪≥最低：✓ 众包结算票：✓
风险点：____ 经办：____
```

注意事项 / 常见坑：
- 退休未领养老金却按返聘，仍可能认劳动关系。
- 实习生当正式工用不签协议，被认事实劳动。
- 众包无票，税务不合规。
