模块 / 场景：社保实操 — 公积金
工具名称：公积金开户增员表
适用场景：为符合条件的员工在住房公积金中心开户并增员，确定缴存基数与比例，保障员工购房提取与贷款权益。
操作步骤 / 方法：
1. 确认员工是否异地已缴，避免重复账户。
2. 收集身份证号、银行卡（还款卡）。
3. 按工资与当地比例定缴存基数。
4. 单位缴存比例5%至12%内选定。
5. 增员后核对个人账户到账。

模板 / 话术（可直接复制）：
```
【公积金开户增员表】
员工：____ 身份证：____ 缴存城市：____
缴存基数：____ 单位比例：____% 个人比例：____%
银行卡号：____ (公积金联名/还款卡)
增员月份：____ 经办：____ 到账确认：____
```

注意事项 / 常见坑：
- 异地重复开户，转移繁琐且易被冻。
- 比例低于5%或随意为0，违反条例。
- 基数与社保脱节，被要求统一补正。
