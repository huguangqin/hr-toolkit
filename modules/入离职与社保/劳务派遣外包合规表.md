模块 / 场景：用工模式 — 派遣/外包
工具名称：劳务派遣外包合规表
适用场景：区分劳务派遣与业务外包的法律边界，控制派遣比例，规范三性岗位，避免假外包真派遣被认定事实劳动关系。
操作步骤 / 方法：
1. 确认岗位符合三性（临时性/辅助性/替代性）。
2. 派遣用工不超总人数10%。
3. 外包须真外包：管结果不管人。
4. 核查供应商资质与社保缴纳。
5. 定期复盘用工模式合规性。

模板 / 话术（可直接复制）：
```
【劳务派遣外包合规表】
模式：派遣✓/外包✓ 岗位：____ 是否三性：____
派遣占比：____% (≤10%)
外包特征：管结果✓ 自主管理✓ 非驻场管控✓
供应商资质：____ 社保缴纳：____ 复核：____
```

注意事项 / 常见坑：
- 假外包真派遣，被认事实劳动关系。
- 派遣超10%，违规整改。
- 非三性岗位用派遣，无效。
