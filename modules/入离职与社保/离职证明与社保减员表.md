模块 / 场景：离职管理 — 减员转移
工具名称：离职证明与社保减员表
适用场景：员工离职后依法出具离职证明，并在社保公积金系统减员，协助办理社保转移，避免影响员工再就业与公司合规。
操作步骤 / 方法：
1. 按法定内容开具离职证明（不必写离职原因）。
2. 最后工作日后15日内出具并交付。
3. 社保公积金系统办理减员。
4. 告知转移接续流程与办理渠道。
5. 档案与材料归档留存。

模板 / 话术（可直接复制）：
```
【离职证明与社保减员表】
员工：____ 身份证：____ 最后工作日：____
离职证明：出具✓ 交付✓ 内容(岗位/年限/无竞业限制)
社保减员月：____ 公积金减员月：____
转移指引：参保凭证✓ 接续渠道告知✓
经办：____ 日期：____
```

注意事项 / 常见坑：
- 离职证明写负面原因，员工可索赔。
- 减员迟办，员工新单位无法增员。
- 扣押证明逼留人，违法。
