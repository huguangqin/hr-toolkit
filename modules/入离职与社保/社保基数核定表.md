模块 / 场景：社保实操 — 基数核定
工具名称：社保基数核定表
适用场景：每年基数调整期，按职工上年月平均工资核定社保与公积金缴费基数，确保不低报、不漏报，规避稽核风险。
操作步骤 / 方法：
1. 取职工上年1至12月应发工资总额。
2. 除以12得月均工资作为基数。
3. 与上下限比对，超限取限、低于限取限。
4. 新员工按首月或约定工资核定。
5. 公示基数，员工签字确认。

模板 / 话术（可直接复制）：
```
【社保基数核定表】
员工：____ 年度：____ 上年应发总额：____
月均工资=总额/12=____ 上下限：[下限____,上限____]
核定基数：____ (超上限取上限/低于下限取下限)
社保基数：____ 公积金基数：____
员工确认签字：____ 日期：____
```

注意事项 / 常见坑：
- 只算基本工资不算奖金，基数被压低。
- 新员工按最低而非首月工资，少缴。
- 不公示不确认，员工事后异议无据。
