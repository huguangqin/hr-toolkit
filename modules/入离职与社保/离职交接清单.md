模块 / 场景：离职管理 — 工作交接
工具名称：离职交接清单
适用场景：员工离职时，把工作、资产、账号权限、未结事项一次性交接清楚，防止客户流失、资料丢失、账号被盗用。
操作步骤 / 方法：
1. 列出在办项目、待跟进客户、关键文档位置。
2. 回收电脑、门禁、车钥匙等实物资产。
3. 停用邮箱、系统、业务账号权限。
4. 财务核对借款、报销、未结佣金。
5. 直属与接手人双签确认交接完成。

模板 / 话术（可直接复制）：
```
【离职交接清单】
员工：____ 部门：____ 最后工作日：____ 接手人：____
一、工作交接
在办项目：____ 待跟客户：____ 关键文档路径：____
二、资产回收
电脑✓ 门禁✓ 车钥匙✓ 证照✓ 其他：____
三、账号权限
邮箱✓ 业务系统✓ IM✓ 门禁✓ (均停用)
四、财务核对
借款：____ 报销：____ 未结佣金：____
交接人：____ 接手人：____ 监交：____ 日期：____
```

注意事项 / 常见坑：
- 账号不回收，离职后仍能登录删数据。
- 客户资源在私人微信，人走客走。
- 借款未清就办离职，欠款难追。
