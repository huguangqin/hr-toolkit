模块 / 场景：入职管理 — 信息建档
工具名称：员工信息登记表
适用场景：收集新员工身份信息、紧急联系人、教育履历、银行账号，建合规人事档案，支撑合同、社保、个税与紧急联络。
操作步骤 / 方法：
1. 报到前发电子表预填，减少现场等待。
2. 报到核验原件，现场更正错填。
3. 录入 HR 系统，敏感字段加密。
4. 员工签字确认信息真实。
5. 按最小可见原则设置查询权限。

模板 / 话术（可直接复制）：
```
【员工信息登记表】
姓名：____ 性别：____ 身份证号：____ 手机号：____
紧急联系人：____ 关系：____ 电话：____
最高学历：____ 毕业院校：____ 专业：____
银行卡(开户行)：____
社保电脑号：____ 公积金账号：____
本人确认以上信息真实准确：签字____ 日期____
```

注意事项 / 常见坑：
- 身份证号明文存共享Excel，泄露被监管处罚。
- 信息错填不核验，导致个税社保全部出错。
- 漏紧急联系人，突发状况无人对接。
