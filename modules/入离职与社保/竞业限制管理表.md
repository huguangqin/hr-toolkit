模块 / 场景：离职管理 — 竞业合规
工具名称：竞业限制管理表
适用场景：对接触核心机密的人员签竞业限制，离职后按月发补偿，期限内监控就业，违约追讨，保护公司商业秘密。
操作步骤 / 方法：
1. 签约前确认人员属法定可限制范围（高管/高技/负保密义）。
2. 约定范围、地域、期限（不超二年）。
3. 离职后按月支付补偿（不低于离职前工资30%）。
4. 建立违约线索收集与取证机制。
5. 违约发函并启动仲裁追偿。

模板 / 话术（可直接复制）：
```
【竞业限制管理表】
员工：____ 岗位：____ 是否涉密：____
限制范围：____ 地域：____ 期限：____月(≤24)
月补偿：____ (≥离职前工资30%)
补偿发放：按月✓ 违约条款：____
监控方式：____ 违约取证：____ 经办：____
```

注意事项 / 常见坑：
- 全员签竞业，范围过宽被认定无效。
- 不付补偿，竞业自动解除。
- 补偿低于30%，条款可能被调整。
