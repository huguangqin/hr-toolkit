模块 / 场景：入职/在职 — 保密与IP
工具名称：保密与知识产权确认表
适用场景：入职签保密协议，明确职务成果归公司，规范数据访问与对外披露，降低商业秘密与专利权属争议。
操作步骤 / 方法：
1. 入职签保密协议，界定涉密信息与期限。
2. 明确职务作品、职务发明归公司所有。
3. 分级数据访问权限，最小授权。
4. 对外披露前走审批流程。
5. 离职时重申保密义务与IP归属。

模板 / 话术（可直接复制）：
```
【保密与知识产权确认表】
员工：____ 部门：____ 入职：____
保密信息范围：____ 保密期限：____
职务成果归属：公司✓ (含代码/设计/发明)
数据权限级别：____ 对外披露审批：✓
离职重申保密义务：✓ 签字：____ 日期：____
```

注意事项 / 常见坑：
- 不签协议，泄密难追责。
- 职务发明权属不清，专利归个人。
- 数据权限过大，内鬼易下手。
关联工具：竞业限制管理表、员工信息登记表、入职手续办理清单
