模块 / 场景：社保合规 — 稽核应对
工具名称：社保税务稽核自查表
适用场景：在税务统征与稽核常态下，定期自查缴费基数、险种、人员覆盖，提前补正，避免被稽核后补缴罚款。
操作步骤 / 方法：
1. 核对在册人数与参保人数是否一致。
2. 复核缴费基数是否含全口径工资。
3. 检查险种是否齐缴、比例是否合规。
4. 排查试用期、实习生、返聘是否漏保。
5. 形成整改清单并限期补正。

模板 / 话术（可直接复制）：
```
【社保税务稽核自查表】
在册人数：____ 参保人数：____ 差异：____
基数全口径：✓/✗ 险种齐全：✓/✗ 比例合规：✓/✗
试用期参保：✓ 实习返聘：✓
问题清单：____
整改时限：____ 责任人：____
```

注意事项 / 常见坑：
- 人数对不上，漏保被稽核。
- 基数不全口径，补差加罚。
- 临时抱佛脚，整改被动。
