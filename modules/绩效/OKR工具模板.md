模块 / 场景：绩效管理 — 目标对齐与挑战法（过程 + 自驱导向）
工具名称：OKR 目标与关键结果工具模板
适用场景：业务不确定高、需要创新和跨部门对齐的团队——研发、产品、增长、创业/转型业务。适合激发自驱、聚焦"跳一跳才够得着"的挑战，且通常不与薪酬强挂钩。若业务成熟、要的是"结果必须达成"，请用 KPI 工具模板；两者可混用而非二选一。
操作步骤 / 方法：
1. 写 O（目标）：定性、鼓舞人心、指明方向，不要写数字（"打造行业第一的面试体验"，不是"满意度提升到 90"）。
2. 写 2–4 个 KR（关键结果）：可量化、有截止日、能量化证明 O 是否达成（"3 个月内把候选人 NPS 从 35 提到 60"）。
3. 对齐：下级 O/KR 要能支撑上级 O（是"对齐"不是"分解数字"），公开透明可互相看。
4. 周/双周 check-in：看进度、调资源、清障碍，不月底才看（节奏详见绩效复盘会模板）。
5. 期末自评 0.0–1.0：0.6–0.7 算优秀（说明目标有挑战），1.0 反而说明目标定低了。

模板 / 话术（可直接复制）：
```
【团队 OKR 卡片】
O（目标）：______________________（定性、鼓舞、不写数）
  KR1：____________________　截止：____　自评：__/1.0
  KR2：____________________　截止：____　自评：__/1.0
  KR3：____________________　截止：____　自评：__/1.0
对齐上级 O：______________________（我这条如何支撑它？）

【评分规则】
0.0 无进展｜0.3 有进展未达｜0.7 达成有挑战（优秀）｜1.0 完全达成（目标偏低）
```

注意事项 / 常见坑：
- 把 OKR 当 KPI 用：KR 写成"完成率 100%"的承诺指标 → 失去挑战性，等于换皮 KPI。
- OKR 与奖金强挂钩：员工不敢设挑战目标，全填保守值，0.7 文化名存实亡。
- O 写虚话："提升业绩""加强协同"没有方向感，团队不知往哪使力。
- 不公开不对齐：各写各的、彼此不可见 → 变成另一个待办清单，失去"对齐"价值。
- 设太多：一个周期 O 别超 3 个、KR 别超 4 个/O，多了焦点散。

关联工具：绩效目标设定模板（挑战型 vs 承诺型分流）、绩效复盘会模板（check-in）
