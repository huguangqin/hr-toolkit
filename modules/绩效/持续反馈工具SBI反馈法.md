模块 / 场景：绩效管理 — 日常反馈
工具名称：持续反馈工具（SBI 反馈法提示卡）
适用场景：日常即时反馈，替代"攒到期末算总账"；正向/负向都可用
操作步骤 / 方法：
1. S 情境（Situation）：说清时间、地点、具体的事
2. B 行为（Behavior）：只描述对方做了什么（不评判、不贴标签）
3. I 影响（Impact）：说明对团队/业务/你造成的影响
4. 正向加"感谢/请复制"，负向加"期待如何调整"

模板 / 话术（可直接复制）：
```
【正向】"昨天评审会(S)，你主动把风险点列了出来(B)，让我们提前避开了返工、省了至少两天(I)。这个习惯值得保持。"
【负向】"今早的需求变更(S)，你直接改了代码没同步测试(B)，导致构建挂了 20 分钟(I)。下次麻烦先拉测试进群同步。"
```

注意事项 / 常见坑：
- 行为描述用动词，不贴标签："你迟到了"✓，"你不靠谱"✗。
- 负向反馈当天给，别攒；正向反馈也别只到期末才说。
- 一对一时给，别当众让人下不来台。
