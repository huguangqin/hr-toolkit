模块 / 场景：绩效管理 — 期末评估
工具名称：上级绩效评估表（行为锚定版）
适用场景：上级对照期初目标与行为锚给员工打分，保证"同标准、可追溯"
操作步骤 / 方法：
1. 先读员工自评 + 期初目标
2. 每项目标按行为锚定给分（1–5），并写事实依据
3. 交叉看同事/下属反馈（360 抽样）补盲区
4. 给总评等级 + 关键正向/待改进事例

模板 / 话术（可直接复制）：
```
【评分卡】
目标：____________ 权重__% 得分(1–5)：__ 事实依据：____________
【行为锚定示例-专业能力】
5分：超出目标，沉淀出可复用方法论　3分：达标　1分：明显未达且需补救
【总评】
等级：□S □A □B □C □D
关键正向事例：____________
关键待改进：____________
```

注意事项 / 常见坑：
- 每一分必须有事实，禁止"印象分""我觉得"。
- 先独立打分再开校准会（先写后聊），避免被先开口的人带节奏。
- 区分"能力不足"与"态度/意愿问题"，二者改进对策完全不同。
