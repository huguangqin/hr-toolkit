模块 / 场景：绩效管理 — 期末评估
工具名称：员工绩效自评表
适用场景：考核期末，让员工先结构化自评，减少"突然被评"的抵触，也为上级提供证据
操作步骤 / 方法：
1. 对照期初目标逐条自评（完成度 + 证据）
2. 写"超出预期的事"和"未达预期的事"各 1–2 条
3. 对照评级标准自评等级（不给自己打满分）
4. 提"需要的支持 / 下一步发展诉求"

模板 / 话术（可直接复制）：
```
【自评表】
姓名：______　考核周期：______　自评等级：□S □A □B □C □D
一、目标达成（逐条）
目标：____________ 完成度：___% 证据/数据：____________
目标：____________ 完成度：___% 证据/数据：____________
二、超出预期的事：____________
三、未达预期及原因：____________
四、所需支持/发展诉求：____________
```

注意事项 / 常见坑：
- 自评≠给自己贴金，要附证据，否则上级不采信。
- 引导写"事"不写"苦劳"："我很努力"不如"我提前 2 天交付且零返工"。
- 自评等级仅作参考，最终以校准后为准，别让自评绑架结果。
