模块 / 场景：绩效管理 — 战略执行框架（多维平衡）
工具名称：BSC 平衡计分卡工具模板
适用场景：中大型企业/集团、事业部做战略落地；解决"只盯财务"的短视，让组织/部门层面在四个维度均衡。个人层较少直接用，多用在组织与部门层级（个人用 KPI/OKR/MBO 更合适）。
操作步骤 / 方法：
1. 画战略地图：财务 → 客户 → 内部流程 → 学习成长，四层自底向上构成因果链。
2. 每层选 1–2 个核心指标 + 目标值，不求多。
3. 打通因果：学习成长驱动内部流程，内部流程驱动客户，客户驱动财务（少一层都断链）。
4. 季度复盘，看四维度是否均衡，避免"财务绿、客户红"的假健康（节奏详见绩效复盘会模板）。

模板 / 话术（可直接复制）：
```
【部门平衡计分卡】
财务层：营收增长__% / 利润率__%（目标：____）
客户层：NPS__ / 份额__%（目标：____）
内部流程层：交付周期__天 / 良率__%（目标：____）
学习成长层：关键人才保留__% / 培训时长__h（目标：____）
战略地图因果：学习(培训)→流程(提效)→客户(体验)→财务(增收)
```

注意事项 / 常见坑：
- 四维度平均用力：没有战略重点，指标散成四张孤立的表。先定"今年主推哪层"。
- 指标间无因果：每层各选各的，拼不出因果链 → BSC 退化为"四张 KPI 表"。
- 只用于考核不用于沟通：BSC 本质是战略沟通工具，不只是打分卡。
- 个人层硬套：个人套四维度太复杂难落地，个人用 KPI/OKR/MBO 更合适。
- 指标过多：每层 1–2 个，总数控制在 8 个内，否则失焦。

关联工具：KPI工具模板（指标落地）、绩效复盘会模板（季度平衡复盘）
