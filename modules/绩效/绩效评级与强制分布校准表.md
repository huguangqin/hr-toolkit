模块 / 场景：绩效管理 — 评级校准
工具名称：绩效评级与强制分布校准表
适用场景：多团队横向拉齐，防止"宽松部门全 A、严厉部门全 C"的不公
操作步骤 / 方法：
1. 定等级定义（S/A/B/C/D 各对应什么）
2. 设强制分布区间（如 S≤10%、A≤20%、B 主体、C≥10%、D 按需）
3. 各部门先独立初评
4. 开校准会：跨主管对齐"同等级标准"，调整越界分布

模板 / 话术（可直接复制）：
```
【等级定义】S卓越(显著超预期) | A优秀(超预期) | B达标 | C待改进(部分未达) | D不合格(明显未达)
【强制分布建议】S≤10%　A≤20%　B 50–60%　C≥10%　D 0–5%
【校准记录】
部门：____ 初评分布 S__A__B__C__D__　校准后 S__A__B__C__D__　调整理由：____
```

注意事项 / 常见坑：
- 强制分布是"校准标尺"不是"摊派"，避免为凑比例乱评。
- 小团队（<5 人）慎用强制分布，极易失真。
- 校准会只看"标准一致性"，不替主管改具体人。
