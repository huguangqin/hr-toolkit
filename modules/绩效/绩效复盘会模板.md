模块 / 场景：绩效管理 — 周期复盘
工具名称：绩效复盘会（季度/年度）模板
适用场景：周期末团队/部门复盘，从"评人"升级到"改系统"
操作步骤 / 方法：
1. 看结果分布（达标率 / 等级分布 / 异常项）
2. 挖根因（是目标定高了？资源不够？还是人？）
3. 提炼"可复用的好做法"和"要改的流程"
4. 输出下周期改进项 + 责任人 + 时限

模板 / 话术（可直接复制）：
```
【复盘四问】
① 这周期目标达成率__%，超预期/未达的分别是哪些？
② 未达的根因（目标/资源/人/外部）？
③ 哪些做法值得沉淀成标准？
④ 下周期改哪 3 件事？谁负责？几月交？
【产出】好实践库：____________ 待改流程：____________ 下季目标调整：____________
```

注意事项 / 常见坑：
- 复盘对事不对人，不重炒个人排名。
- 结论要"有 owner 有 deadline"，否则白开。
- 好的复盘会产出"制度改进"，不是"检讨大会"。
