模块 / 场景：绩效管理 — 低绩效改善
工具名称：绩效改进计划 PIP 模板
适用场景：评级 C/D 或能力明显短板，给员工 30–60 天结构化改进期，留痕合规
操作步骤 / 方法：
1. 明确差距项（具体哪项未达、差多少）
2. 列改进目标 + 衡量标准 + 资源支持 + 时间节点
3. 约定检查节奏（周 / 双周）
4. 双方签字，HR 备案

模板 / 话术（可直接复制）：
```
【PIP】员工：______ 改进周期：__天 主管：______ HR：______
差距项：____________ 现状数据：____________
改进目标：____________ 衡量标准：____________
支持资源：____________ 检查节点：第__周 / 第__周
未达标后果（提前告知）：□ 延长PIP □ 调岗 □ 解除
双方签字：____________ 日期：______
```

注意事项 / 常见坑：
- PIP 是"帮改进"不是"凑解除证据"，目标要可达、可衡量。
- 全程书面留痕，每次检查都记录，避免劳动风险。
- 给足支持仍无改善，再走处置流程。

关联工具：不胜任员工认定与处理流程、上级绩效评估表
