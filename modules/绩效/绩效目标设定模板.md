模块 / 场景：绩效管理 — 目标设定
工具名称：绩效目标设定模板（KPI / OKR + SMART 校验）
适用场景：考核周期初（年度/季度）与员工对齐目标，把"公司战略"拆成"个人可衡量的事"
操作步骤 / 方法：
1. 自上而下拆解：公司目标 → 部门目标 → 团队目标 → 个人目标（层层对齐不脱节）
2. 给每项目标配"衡量标准 + 权重 + 时限"
3. 用 SMART 逐条校验（具体/可衡量/可达/相关/有时限）
4. 区分 KPI（承诺型，必须达成）与 OKR（挑战型，允许失败）
5. 双方签字确认，作为期末评估与校准的依据

模板 / 话术（可直接复制）：
```
【个人绩效目标表】
目标1：___________　类型：□KPI □OKR　权重：__%　时限：____（年月日）
衡量标准（可量化）：________________________
SMART 自检：具体□ 可衡量□ 可达□ 相关□ 时限□
目标2：___________
类型：□KPI □OKR　权重：__%　时限：____　衡量标准：________________

【SMART 五问校验句】
这条写清楚了吗？— 拿什么数证明完成？— 跳一跳够得着吗？
和本职相关吗？— 几月几日前交？
```

注意事项 / 常见坑：
- 目标不是职责罗列："负责招聘"不是目标，"Q3 到岗 30 人且 3 个月留存率≥85%"才是。
- 权重总和须=100%；单项目标权重别低于 5%（否则没意义），也别高于 40%（避免一票独大）。
- 别给全员套同一套死指标，业务差异要体现。

关联工具：绩效指标库（指标来源）、上级绩效评估表（期末对照）
