模块 / 场景：绩效管理 — 申诉与公平
工具名称：绩效申诉处理流程
适用场景：员工对评级/结果有异议，走正式渠道，避免私下抱怨发酵成离职
操作步骤 / 方法：
1. 公示申诉窗口（结果发布后 5 个工作日内）
2. 员工书面提交，说明异议点
3. 原主管回避，由校准委员会/HR 复核证据
4. 出具结论（维持/调整）并书面反馈

模板 / 话术（可直接复制）：
```
【申诉表】员工：______ 异议事项：______ 理由/证据：______ 期望：______
【处理 SLA】受理3日内回复 → 复核7日内出结论 → 书面反馈并归档
【结论】□ 维持 □ 调整(改为__级) 复核人：______ 日期：______
```

注意事项 / 常见坑：
- 申诉期间结果"不冻结但不生效"，避免影响薪酬等其他流程。
- 复核看证据不看关系，结论书面留痕。
- 保护申诉人，严禁打击报复。

关联工具：绩效评级与强制分布校准表、不胜任员工认定与处理流程
