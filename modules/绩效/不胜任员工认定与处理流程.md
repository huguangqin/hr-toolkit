模块 / 场景：绩效管理 — 低绩效处置
工具名称：不胜任员工认定与处理流程
适用场景：经 PIP/培训仍不胜任，依法合规推进调岗或解除，控劳动风险
操作步骤 / 方法：
1. 确认"不胜任"证据链（目标未达 + PIP 记录 + 培训记录）
2. 先培训或调岗（法律要求先给改进机会）
3. 仍不胜任，提前 30 天书面通知或支付代通知金
4. 经济补偿 + 离职面谈，合规闭环

模板 / 话术（可直接复制）：
```
【认定三要件】
① 有书面岗位标准/目标　② 有未达证据　③ 经培训或调岗仍不达标
【处置选项】□ 培训后复核 □ 调岗(书面) □ 协商解除(N+1) □ 单方解除(须满足法定情形)
```

注意事项 / 常见坑：
- 不能直接"不胜任就开除"，须先培训/调岗，否则构成违法解除。
- 所有环节书面留痕，员工拒签则邮件/公证送达。
- 涉及医疗期、孕期/产期/哺乳期女职工等受保护群体，先咨询法务。
