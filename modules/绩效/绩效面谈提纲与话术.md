模块 / 场景：绩效管理 — 反馈沟通
工具名称：绩效面谈提纲与话术（1对1）
适用场景：期末/日常 1对1，把"分数"变成"共识与行动"，避免面谈变批斗
操作步骤 / 方法：
1. 提前发自评表，让对方有准备
2. 用"事实 → 影响 → 期待"结构开场，不先抛等级
3. 让员工先说，上级多听少辩
4. 共识改进点，落进发展计划

模板 / 话术（可直接复制）：
```
【开场】"今天不是宣判，是一起看过去这周期你做得怎样、下一步怎么更好。你先说说自己的感受？"
【谈优势】"这季度你做的__，数据上提升__%，我很认可。具体哪一步最关键？"
【谈差距】"有件事想对齐：__这事，当时结果是__，对团队影响是__。你怎么看？"
【收尾】"那我们定两个小目标：__ 和 __，下周期复盘。需要我什么支持？"
```

注意事项 / 常见坑：
- 不翻超过本周期的旧账；不拿"别人比你强"做比较。
- 差距谈事实不谈人格："交付晚了"≠"你不负责任"。
- 面谈后 24h 内发纪要，双方确认，避免"说了等于没说"。
