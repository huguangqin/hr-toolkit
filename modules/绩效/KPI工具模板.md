模块 / 场景：绩效管理 — 指标考核法（结果导向）
工具名称：KPI 关键绩效指标工具模板
适用场景：业务成熟稳定、结果可量化、需要强结果管控的岗位与团队——销售（签约/回款）、生产（产量/良率）、客服（响应/SLA）、职能（流程 SLA/满意度）。适合把"公司战略"翻译成"必须达成的数字"，并对结果强考核。若你的业务高度不确定、需要的是"对齐和试错"而非"管控结果"，请看 OKR 工具模板。
操作步骤 / 方法：
1. 自上而下解码：公司级北极星指标 → 部门 KPI → 个人 KPI，层层对齐不脱节。
2. 先定 1 个"北极星指标"（最能代表业务健康的那一个），再拆 3–5 个驱动指标。
3. 每指标给全六要素：定义 + 计算公式 + 目标值 + 权重 + 数据来源 + 红黄绿灯阈值。
4. 期末按"实际值÷目标值"算达成率，映射得分，与薪酬/奖金强挂钩。
5. 指标每季度滚动复盘，废掉失真/失效的指标（详见绩效复盘会模板）。

模板 / 话术（可直接复制）：
```
【个人 KPI 表】
指标 | 定义 | 公式 | 目标值 | 权重 | 数据来源 | 红/黄/绿灯阈值 | 实际 | 达成率 | 得分
销售签约额 | 新签合同金额 | CRM 合同额 | 500万 | 30% | CRM | 红<400 黄400-500 绿≥500 | | |
回款率 | 实收/应收 | 财务系统 | 90% | 25% | 财务 | 红<80 黄80-90 绿≥90 | | |
客户满意度 | NPS | 问卷 | 40 | 15% | 问卷 | 红<30 黄30-40 绿≥40 | | |
（每岗 5–7 个封顶）

【达成率→得分映射】
达成率≥100% 得满分；80–100% 线性得分；<80% 该项封顶 0.6 倍权重分（避免一俊遮百丑）。
```

注意事项 / 常见坑：
- 指标越多越乱：单岗 5–7 个封顶，多了重点模糊、员工无所适从。
- 只考结果不考过程：销售为冲量乱承诺客户、客服为降时长挂断电话——给结果指标配"质量护栏"（如客户满意度、合规率）。
- 目标值拍脑袋：太高变形式主义（人人 0 分），太低没挑战（人人满分）。用"去年实际 + 行业基准 + 战略增量"三结合定。
- 数据来源不可靠：期末必扯皮。指标上线前先确认"这个数系统里能自动取吗"，不能就别列入考核。

关联工具：绩效指标库（指标来源）、绩效目标设定模板（KPI/OKR 分流）、绩效结果应用矩阵（得分→薪酬）
