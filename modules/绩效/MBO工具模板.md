模块 / 场景：绩效管理 — 目标管理法（上下共识导向）
工具名称：MBO 目标管理工具模板
适用场景：知识型/专业型岗位、中后台、管理岗；企业文化偏信任、团队成熟度较高。强调上下级"共同商定目标"并写下承诺，重发展而非纯管控。它是 KPI/OKR 的"老祖宗"（德鲁克 1954 年提出），现代多数考核法都从它演化而来。
操作步骤 / 方法：
1. 上级给方向，下属提目标草案（自下而上），不单向下派。
2. 一对一沟通，双方对目标达成共识、形成书面承诺。
3. 聚焦 3–5 个"关键结果领域（KRAs）"，不是把全部职责列成清单。
4. 执行中定期回顾（月度为宜），上级当教练而非监工。
5. 期末对照"承诺 vs 实际"，谈达成度、谈原因、谈下一步，结果主要用于发展。

模板 / 话术（可直接复制）：
```
【MBO 目标承诺卡】
姓名：______　周期：______　上级：______
关键结果领域1：__________　承诺目标：__________　实际：__________　达成度：□超□达□未
关键结果领域2：__________　承诺目标：__________　实际：__________　达成度：□超□达□未
关键结果领域3：__________　承诺目标：__________　实际：__________　达成度：□超□达□未
共识记录（双方签字）：上级____ 员工____ 日期____
期末复盘结论：________________________________________
```

注意事项 / 常见坑：
- 没有共识变"下压任务"：上级直接定、员工被动接 → 失去 MBO 精髓（共同商定）。
- 目标=职责清单：写"负责招聘、负责培训"，没有"做到什么程度"，期末无法评价。要写"做到什么结果"。
- 只定不跟：期末才看，错过纠偏窗口。月度回顾不能省。
- 和 KPI 混为一谈：MBO 不强调量化硬指标，强调"上下共识的承诺"；把它当成纯数字考核就丢了原味。
- 结果只用于奖惩：MBO 本意是"自我控制 + 发展"，全变扣钱工具会挫伤承诺感。
