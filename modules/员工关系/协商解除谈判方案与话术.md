模块 / 场景：员工关系与劳动法合规 — 劳动关系解除
工具名称：协商解除谈判方案与话术
适用场景：公司拟与员工协商解除劳动合同时，设计方案、准备谈判话术、起草协议，控制法律风险与成本
操作步骤 / 方法：
1. 评估解除必要性与法律依据 → 确定走协商解除而非单方解除
2. 测算经济补偿方案（N / N+1 / 谈判空间）→ 预批预算
3. 准备谈判话术与应对预案 → 确定谈判人（HR + 业务负责人）
4. 正式谈判 → 达成一致 → 签署协议
5. 履行协议 → 结算 → 离职办理

模板 / 话术（可直接复制）：
```
【协商解除补偿测算表】
员工：______ 司龄：__年__个月（满半年按1年算）　月均工资：¥______

经济补偿 N = 司龄 × 月均工资 = ¥______
代通知金 +1 = ¥______
方案 A（底线）：N = ¥______
方案 B（预期成交）：N+1 = ¥______
方案 C（谈判上限）：N+1+绩效奖金折算 = ¥______

注意事项：
- 月均工资 = 离职前 12 个月平均应得工资（含奖金/补贴/加班费）
- 月均工资超当地社平工资 3 倍的，按 3 倍封顶，司龄最长不超过 12 年
- 协商解除无需"提前 30 天通知"，日期双方约定即可
```

```
【谈判话术参考】

开场定调（降低对抗感）
"今天约你聊，是想和你坦诚沟通一下接下来的安排。公司在做组织调整/岗位优化，
涉及你的岗位会有变化。我们希望能找到一个双方都能接受的方式，
所以想先听听你的想法。"

抛出方案
"公司提出的方案是协商解除劳动合同，补偿按法定标准 N+1，合计 ¥______。
离职日期可以约定在 __月__日，这期间你正常出勤、工资照发。
这个方案你先了解一下，不用马上回复。"

应对：员工要 2N
"我理解你的想法。2N 是违法解除的赔偿标准，前提是公司违法解除劳动合同。
我们现在走的是协商解除，双方自愿达成一致，适用的是 N 或 N+1 的补偿标准。
我们不会强行解除，是希望和你商量着来。"

应对：员工说"我不签，你们开除我啊"
"我们不会走到那一步。协商解除是第一选择，因为它对双方都是最干净的方式——
你拿到补偿、不用走仲裁，公司也避免纠纷。如果协商不成，公司也会依法处理，
但那时候流程会更长，对你的职业过渡也不一定有利。"

应对：员工要更多时间考虑
"完全可以，你回去考虑一下。我们约 __天后（具体日期）再谈一次。
期间有任何问题随时找我。"

达成一致
"好的，那我们按 ¥______ 的方案来。我准备协议，明天给你看，没问题的话
就签字。离职日期定在 __月__日，交接安排我们再细聊。"
```

```
【协商解除协议关键条款清单】
□ 解除日期与最后工作日
□ 经济补偿金额、支付方式与时间（离职后 X 个工作日内一次性支付）
□ 工资/加班费/年休假/报销的结清方式
□ 社保公积金减员时点
□ 保密义务延续条款
□ 竞业限制条款（如适用，含补偿标准与期限）
□ 一次性了结声明（"双方就劳动关系的权利义务已全部结清，互不追究"）
□ 禁止反言条款（员工承诺不以任何理由再向公司主张权利）
□ 争议解决条款（协商不成提交劳动仲裁）
```

注意事项 / 常见坑：
- **协议里的"一次性了结"是护身符**：协议中务必写明"双方就劳动关系存续期间的全部权利义务已结清，互不再追究"。没有这句话，员工拿了补偿后仍可就加班费、年休假、未缴社保等单项另行主张。但注意：社保补缴不在协商范围（社保是法定义务，不能协议免除）。
- **协商解除 ≠ 辞退**：协商解除是双方合意，《劳动合同法》第 36 条。员工主动提出协商解除的，公司无需支付经济补偿；公司提出的，应当支付。谈判中要明确是"公司提出协商"。
- **不要威胁**：谈判中说"不签就给你调岗/降薪/开除"可能构成胁迫，协议可能被撤销。正确的姿态是"协商不成各自依法走流程"。
- **录音不是必须的，但建议有**：谈判现场建议两人以上参与（HR + 业务负责人），做好书面记录。条件允许时可以录音备查，但不必告知（单方录音在劳动争议中一般可采信）。
- **签了协议就尽快履行**：协议约定了付款时间的，务必按时支付。逾期不付的，员工可能以公司违约为由撤销协议或主张额外赔偿。
