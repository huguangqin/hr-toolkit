模块 / 场景：员工关系与劳动法合规 — 特殊群体保护
工具名称：特殊群体保护红线清单
适用场景：涉及女职工（孕期/产期/哺乳期）、工伤职工、医疗期员工、未成年工等受法律特殊保护群体时，逐项确认不得触碰的红线
操作步骤 / 方法：
1. 确认员工是否属于法定特殊保护群体
2. 对照下表确认保护期限与禁止行为
3. 任何解除/调岗/降薪决定前，先核查是否触碰红线
4. 存疑时先咨询法务/外部律师，再做决定

模板 / 话术（可直接复制）：
```
【特殊群体保护红线速查表】

┌──────────┬────────────────────┬────────────────────────────────────┐
│ 保护群体　　　 │ 保护期限/范围　　　　 │ 红线行为（以下操作=违法解除/违法行为） │
├──────────┼────────────────────┼────────────────────────────────────┤
│ 孕期女职工　　 │ 怀孕至分娩　　　　　　 │ 解除劳动合同 / 降薪 / 岗位调整为禁忌劳动 │
│ 产期女职工　　 │ 产假期间（98天+地方奖励假）│ 解除劳动合同 / 降薪 / 不发放产假津贴　　 │
│ 哺乳期女职工　 │ 产后至婴儿满 1 周岁　 │ 解除劳动合同 / 安排夜班 / 延长劳动时间　 │
│ 工伤职工(1-6级)│ 工伤认定后　　　　　　 │ 解除劳动合同（员工主动除外）/ 停发停工留薪期工资 │
│ 工伤职工(7-10级)│ 工伤认定后　　　　　 │ 劳动合同期满不得终止（须延至相应情形消失）│
│ 医疗期员工　　 │ 按司龄计算（3-24个月）│ 医疗期内解除劳动合同 / 不发医疗期工资　　 │
│ 未成年工　　　 │ 16-18周岁　　　　　　 │ 安排禁忌劳动 / 不安排定期体检 / 过量加班 │
│ 老员工(满15年) │ 距退休不足5年　　　　 │ 以客观情况变化/不胜任为由解除劳动合同　　 │
└──────────┴────────────────────┴────────────────────────────────────┘

※ 以上为全国性规定，各地可能有更严格的补充规定（如产假天数、医疗期工资标准），以当地政策为准。
```

```
【女职工"三期"管理操作要点】
一、孕期
□ 不得安排禁忌劳动（高空/高温/冷水/放射性等）
□ 不得安排加班（怀孕7个月后）和夜班
□ 产前检查时间计入劳动时间（不扣薪）

二、产期
□ 产假不少于 98 天（难产+15天；多胞胎每多一个+15天）
□ 地方奖励假按当地规定执行（如北京+60天）
□ 产假期间发放产假津贴（生育保险支付；未参保的由公司按原工资支付）
□ 男职工陪产假按当地规定执行

三、哺乳期
□ 哺乳时间每天 1 小时（多胞胎每多一个+1小时），计入劳动时间
□ 不得安排夜班和加班
□ 哺乳期至婴儿满 1 周岁
```

注意事项 / 常见坑：
- **"三期"不是免死金牌**：孕期/产期/哺乳期女职工不能适用《劳动合同法》第 40 条（无过失性辞退）和第 41 条（经济性裁员）解除，但**仍可适用第 39 条**（严重违纪）解除。即：三期员工严重违纪，照样可以开除，且无需经济补偿。但举证要求更高，务必证据充分。
- **"调岗降薪"要协商**：不能以怀孕为由单方调岗降薪。确需调整工作岗位的，须与员工协商一致并书面确认。因身体原因不能胜任原岗位的，应根据医疗机构的证明予以减轻劳动量或安排其他能够适应的岗位。
- **工伤"私了"协议可能无效**：发生工伤后与员工签"一次性了结"协议的，如果赔偿明显低于法定标准，员工事后可申请撤销。工伤认定和待遇是法定权利，不能通过协议免除。
- **医疗期工资不能停**：医疗期内员工病假，公司须按当地标准支付病假工资（一般为本人工资的 60%-100%，但不得低于最低工资的 80%）。停发工资 = 违法。
- **未成年工体检是法定义务**：招用 16-18 周岁未成年工的，须安排上岗前、定期健康检查，不得安排从事矿山井下、有毒有害、高空等禁忌劳动。漏检的，属违法行为。
