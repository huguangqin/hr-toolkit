模块 / 场景：员工关系与劳动法合规 — 离职管理
工具名称：离职面谈提纲与话术
适用场景：员工提出离职或公司提出解除时，进行结构化离职面谈，挖掘真实离职原因、评估挽留价值、收集管理改进线索
操作步骤 / 方法：
1. 面谈前准备：查阅员工档案（绩效、薪酬、考勤、入司时间），预判离职动机
2. 营造氛围：选择私密空间，说明面谈目的与保密原则
3. 按提纲逐项展开，先开放式提问，后追问细节
4. 评估挽留价值与可行性，给出反馈
5. 整理面谈记录，归档，形成离职分析报告

模板 / 话术（可直接复制）：
```
【离职面谈提纲】
员工：______ 入司日期：______ 面谈日期：______ 面谈人：______

一、离职决策
1. "你是什么时候开始考虑离职的？" → 判断决策时长
2. "促使你做出这个决定的最主要原因是什么？" → 核心动因
3. "除了这个原因，还有哪些因素影响了你的决定？" → 次要因素
4. "新机会最吸引你的是什么？"（薪酬/职位/行业/团队/发展空间）

二、工作体验
5. "你在公司最有成就感的时刻是什么？"
6. "你觉得最需要改进的地方是什么？" → 管理改进线索
7. "你和直接主管的沟通协作感受如何？" → 管理者诊断
8. "团队氛围和公司文化方面，你有什么想说的？"

三、挽留评估（仅针对公司希望留住的员工）
9. "如果______（具体条件：加薪/调岗/换团队）能解决你的顾虑，你是否愿意重新考虑？"
10. （如不愿留）"我理解你的决定，祝福你。"

四、交接安排
11. "离职时间你计划怎么安排？交接工作你有什么建议？"
12. "离职后联系方式方便留一个吗？方便后续跟进。"

面谈人记录摘要：________________________
是否挽留：□是（方案：______） □否
```

```
【常见场景话术参考】
场景一：薪酬原因离职
"我理解薪酬是你考虑的重要因素。坦白说，目前的薪酬体系下__（说明公司情况）__。
如果能在现有框架内争取调整，你期望的范围是？我帮你评估可行性。"

场景二：与主管矛盾离职
"谢谢你愿意跟我说这些。我记下了你提到的情况，这部分我会单独跟进，不会影响你的离职流程。
你能多说说具体是哪些事情让你感到不舒服吗？"

场景三：核心员工被挖角
"说实话我挺舍不得你走。你在______项目上的贡献大家都有目共睹。
我想了解一下对方给到的是什么条件，如果你愿意，我们看看公司能不能匹配。"

场景四：员工情绪激动
"我能感受到你现在很不好受。不着急，我们慢慢聊。今天聊的内容只有我和HR总监知道，
不会传到任何不该知道的人那里。"
```

注意事项 / 常见坑：
- **别在面谈里"说教"**：离职面谈的目的不是说服员工留下来，而是听真实想法。员工已经决定走了，说教只会让对方闭嘴，你什么有价值的信息都拿不到。
- **"主管问题"要交叉验证**：多个离职员工提到同一个主管时，这不是巧合，是管理风险信号。但单一来源不等于定论，要结合绩效数据、360 评估等交叉验证。
- **挽留要真诚，别画饼**：如果决定挽留，给的条件要具体、可执行（加多少薪/调什么岗），不要"回去我帮你争取争取"然后石沉大海。画一次饼，损失的不止是一个人。
- **离职面谈 ≠ HRBP 一个人聊**：直属主管应在面谈前做一次非正式沟通（"听你说要走，挺意外的，能聊聊吗"），HR 再做正式离职面谈，两份信息拼起来才完整。
- **面谈数据要沉淀**：单次面谈价值有限，按季度/半年度汇总分析离职原因分布、部门离职率、主管关联性，才能发现系统性问题。
