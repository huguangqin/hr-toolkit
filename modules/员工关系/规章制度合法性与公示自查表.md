模块 / 场景：员工关系与劳动法合规 — 规章制度管理
工具名称：规章制度合法性与公示自查表
适用场景：制定或修订员工手册/规章制度时，核查内容合法性与程序合规性，确保制度在劳动争议中可作为有效裁判依据
操作步骤 / 方法：
1. 内容合法性审查：逐条对照法律法规，剔除违法条款
2. 民主程序：经职工代表大会或全体职工讨论 → 提出方案和意见 → 与工会或职工代表平等协商确定
3. 公示程序：选择有效公示方式并留存证据
4. 定期复核更新，法律法规变化时及时修订

模板 / 话术（可直接复制）：
```
【规章制度合法性自查表】
制度名称：______________ 制定/修订日期：______

一、内容合法性审查
□ 无低于法定标准的条款（如低于最低工资、法定加班费不打折等）
□ 罚款条款已删除（企业无权对员工"罚款"，可改为扣减绩效/纪律处分）
□ 搜索/扣押证件条款已删除（不得扣押居民身份证等证件）
□ 不得约定"自愿放弃社保""工伤概不负责"等无效条款
□ 考勤/加班/休假条款与法定标准一致
□ 解除条件不超出《劳动合同法》第 39/40 条范围

二、民主程序留痕
□ 职工代表大会或全体职工讨论记录（日期、参会人员签到、讨论内容）
□ 员工意见汇总及修改说明（采纳/不采纳均需记录理由）
□ 与工会或职工代表平等协商确定记录
□ 工会/职工代表签字确认

三、公示方式（至少选一种，留存证据）
□ 方式一：员工手册签收（每位员工签字确认"已阅读并知晓"）
□ 方式二：公司内网/OA系统发布 + 阅读确认记录
□ 方式三：培训签到（制度培训会签到表 + 培训内容记录）
□ 方式四：电子邮件发送 + 已读回执
□ 方式五：公告栏张贴拍照（须能证明员工可看到）

四、版本管理
□ 制度版本号：v______
□ 生效日期：______
□ 修订记录留存（旧版归档、修订对比表）
□ 修订后重新走民主程序 + 重新公示
```

注意事项 / 常见坑：
- **"制度发邮件了"不等于"有效公示"**：劳动争议中最常翻车的就是公示环节。仅发邮件/发群通知而员工未确认阅读，法院可能认定未完成公示义务。最佳做法是员工手册签收确认（纸质签字或 OA 电子签确认）。
- **民主程序不是走过场**：2008 年《劳动合同法》实施后，直接涉及劳动者切身利益的规章制度（劳动报酬、工时、休息休假、劳动安全卫生、保险福利、职工培训、劳动纪律、劳动定额管理等）必须经过民主程序，否则不能作为管理依据。
- **"罚款"条款无效**：企业无权对员工处以罚款。常见的替代手段是将违纪行为与绩效工资挂钩（在制度中事先明确对应关系），或依《工资支付暂行规定》因劳动者本人原因造成经济损失的，可从工资中扣除赔偿（每月扣除不超过当月工资 20%，剩余不低于最低工资）。
- **修订≠新发**：制度修订后必须重新走民主程序 + 重新公示，不能沿用旧版的公示效力。
- **电子公示要可验证**：用 OA/内网公示的，系统须能导出员工"已阅读"的操作日志和时间戳，仅"发布了"不够。
