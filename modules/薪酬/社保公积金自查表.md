模块 / 场景：薪酬合规 — 社保公积金
工具名称：社保公积金合规自查表
适用场景：社保稽查/审计前自查、年年调基前核对、发现"按最低基数缴"等历史违规并补救
操作步骤 / 方法：
1. 核对缴费基数：以员工上年度月平均工资（应发，含奖金津贴）为基数，非最低工资、非基本工资
2. 核对险种全覆盖：养老/医疗/失业（个人+单位）、工伤/生育（单位）是否全员足额
3. 核对公积金：缴存基数与比例是否在属地规定区间，是否全员（含试用期）
4. 查历史欠账：过去有无按最低基数、漏缴试用期、异地代缴等违规
5. 出整改：补差 + 制度修订 + 留痕，重大违规咨询专业机构

模板 / 话术（可直接复制）：
```
【社保公积金合规自查清单】
员工：______  所属月：______

□ 缴费基数 = 上年月均工资（应发，含奖金/津贴/补贴）？
   实际基数______  应基______  差额______
□ 试用期是否参保？（用工之日起30日内须参保，不得"转正才缴"）
□ 全部险种足额？（养老/医疗/失业/工伤/生育，按属地比例）
□ 公积金是否缴？（基数合规 + 比例在区间 + 全员含试用期）
□ 有无"最低基数代缴""异地第三方代缴"等灰色操作？
□ 离职当月是否缴？（离职当月仍建任用，须缴至停保月）

风险等级：差额>20% 或 漏缴>3人 → 红（高危，优先补）
```

注意事项 / 常见坑：
- **"按最低基数交"是最大雷**：很多公司为省成本按最低基数缴，看似省 20%，稽查一来要补缴本金 + 滞纳金 + 可能罚款，算总账赔数倍。基数必须 = 上年应发平均工资。
- **试用期不缴违法**：用工之日起 30 日内须为员工办理社保登记，以"转正才缴"为由拒缴=违规，员工可投诉。
- **"折现给员工不缴"无效**：和员工签"自愿不缴、公司折现"协议，法律不认，员工仍可要求补缴，公司还得补单位部分。
- **异地代缴风险**：没在当地设分支机构却用第三方代缴，部分地区视为虚构劳动关系，工伤理赔时易扯皮。真异地用工应设分公司或走合规派遣。
- **社保入税后监管更密**：社保费征管职责划转税务后，数据打通，基数不实更易被比对发现，侥幸空间变小。
