模块 / 场景：薪酬管理 — 薪酬沟通
工具名称：薪酬沟通与涨薪谈判话术
适用场景：年度调薪沟通、员工质疑"为什么他涨得多"、谈 offer、处理薪酬保密边界与期望值
操作步骤 / 方法：
1. 定边界：先明确公司薪酬保密政策（哪些能说、哪些不能说），避免主管随口承诺
2. 备数据：沟通前拉出该员工的绩效、CR（薪酬渗透率）、同级对比，做到"有理有据"
3. 用结构化话术：认可贡献 → 给依据（绩效/位置）→ 说差距与路径，不比较他人
4. 管期望：对"想多涨"的员工，给"下次涨的条件"而非空头承诺
5. 留记录：沟通要点邮件/系统留痕，防后续争议

模板 / 话术（可直接复制）：
```
【涨薪沟通四步话术】
1) 认可："今年你负责的XX项目超预期，团队都看到了。"
2) 给依据："你的绩效是A，但薪酬目前低于这级中位约10%，
           所以这次按调薪矩阵给你涨7%，到____。"
3) 不比人："每个人的基数和位置不同，我不便透露他人，
           但你的涨幅在同级A档里是偏高的。"
4) 给路径："想再上一个台阶，明年目标是从B到A级、
           或承担XX职责，到时候CR到中位就能再调。"

【员工问"为什么他涨得比我多"】
❌ "他比你辛苦/他找老板谈了"（引发比较与投机）
✅ "调薪看绩效和当前薪酬位置两个维度，你这次在X维度还有空间，
   我们一起把明年目标定清楚，下次就能补上。"
```

注意事项 / 常见坑：
- **"他找老板谈了所以涨得多"是雷**：随口一句让全员学会"闹着涨"，且泄露他人信息违反保密。永远用"维度"解释，不暴露他人。
- **只说数字不说依据 = 员工觉得随意**：员工要的是"我凭什么"，给绩效+位置两个硬依据，比"公司统一5%"服众十倍。
- **口头承诺不落地 = 信任破产**：主管说"明年肯定给你涨"，没写进系统/目标，到了没涨，员工直接离职。承诺必须绑定可验证的目标。
- **薪酬保密≠薪酬神秘**：完全不解释会让员工猜疑。可公开"制度、规则、自己位置区间"，保密"他人具体数、公式参数细节"。
- **谈崩先共情再给路径**：员工情绪激动时先接情绪（"我理解你觉得不公平"），再给事实与路径，硬怼只会激化。
