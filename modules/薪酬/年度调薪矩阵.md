模块 / 场景：薪酬调整 — 年度调薪
工具名称：年度调薪矩阵（绩效 × 薪酬渗透率）
适用场景：年度普调、预算有限时把涨薪精准给到"高绩效 + 低薪酬"的人，避免"大锅饭"或"倒挂"
操作步骤 / 方法：
1. 算薪酬渗透率 CR（Compa-Ratio）= 员工当前薪资 ÷ 该级 mid。CR<0.85 偏低、0.85-1.15 正常、>1.15 偏高
2. 取员工上一年绩效等级（S/A/B/C/D）
3. 用矩阵交叉定调薪幅度：高绩效×低 CR = 多涨；低绩效×高 CR = 不涨甚至冻
4. 套总预算校验：矩阵算出的总涨幅不得超预算，超了从"高 CR"行砍
5. 一对一沟通：涨的讲原因，不涨的讲差距与路径

模板 / 话术（可直接复制）：
```
【年度调薪矩阵（merit matrix）】
横轴=绩效等级  纵轴=薪酬渗透率CR

        CR<0.85   0.85-1.0   1.0-1.15   >1.15
S(卓越)   +12%      +9%        +6%       +3%
A(优秀)   +9%       +7%        +4%       +2%
B(良好)   +6%       +4%        +2%       0%
C(待改)   +3%       0%         0%        -2%
D(不合格)  0%        0%        -5%       -8%

例：绩效A、CR=0.9 的员工 → 查表 +7%；绩效C、CR=1.1 → 0%（不涨）
```

注意事项 / 常见坑：
- **只按绩效调薪 = 倒挂**：绩效好的老员工 CR 已高（工资不低），新人 CR 低，结果新人涨得多、老人觉得"干得好不如来得晚"，好员工流失。必须叠加 CR 维度。
- **CR 用 mid 不是 max**：用 max 当分母会人人显得偏低、全员普涨，失控。mid（市场 P50）才是合理锚。
- **矩阵要配预算封顶**：先算总盘（如涨薪预算 = 工资总额 5%），矩阵跑完超了，从"高 CR 行"逆序削减，别从"低 CR 高绩效"砍——那砍的是最该留的人。
- **C/D 级负向调整要谨慎**：直接降薪易触发离职/仲裁，多用"冻涨 + 改进计划"替代，真要降需有绩效改进(PIP)证据。
- **沟通要透明到"维度"**：告诉员工"你涨 X% 是因为绩效 A 且薪酬低于中位"，比"公司统一涨 5%"更服众。
