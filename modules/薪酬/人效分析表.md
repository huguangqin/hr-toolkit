模块 / 场景：薪酬效能 — 人效诊断
工具名称：人效与人力成本分析表（薪酬 ROI）
适用场景：老板问"工资花得值不值"、裁员/扩招决策前、薪酬总额与利润挂钩诊断
操作步骤 / 方法：
1. 选人效指标：人均营收、人均利润、人力成本占营收比、每元薪酬产出（营收/薪酬总额）
2. 取数：财务出营收/利润，HR 出人数/薪酬总额（含社保、奖金）
3. 算趋势：同比、环比，看"工资涨了但人效没涨"的背离
4. 分层看：按部门/业务线算人效，找出"高成本低产出"单元
5. 出动作：人效低的单元控编或提效；人效高且缺人的单元加编

模板 / 话术（可直接复制）：
```
【人效与人力成本分析表】
周期：____年____季   单位：万元

指标                本期   上期   变化   判断
营收                1000   900   +11%  ↑
薪酬总额(含社保)    300   260   +15%  ↑
人均营收            125   120   +4%   ↑
人均利润            30    28    +7%   ↑
人力成本/营收       30%   29%   +1pct ↓(略升)
每元薪酬产出        3.33  3.46  -4%   ↓(薪酬涨快于产出)

预警：薪酬增速(15%) > 营收增速(11%) > 人效增速(4%)
→ 钱主要花在"涨工资"而非"提效率"，需控总盘或提效。
```

注意事项 / 常见坑：
- **只看"工资涨了多少"不看"产出涨多少"**：工资涨 20% 不可怕，可怕的是人效没动。必须 pair 看"薪酬增速 vs 人效增速"，背离就是预警。
- **人力成本口径不全**：只算底薪不算奖金/社保/培训，低估真实成本，人效被高估。用"总薪酬包"（含所有现金 + 社保）才准。
- **跨业务线不能平均比**：研发部门人效（人均营收）天然低于销售，直接比会误杀研发。按"价值创造方式"分层看，或看"投入产出比"而非绝对营收。
- **人效低≠立刻裁**：低人效可能是新业务投入期、或流程问题，先诊断"是人不行的还是系统不行的"，裁人治标不治本。
- **人效要连薪酬一起看**：涨薪前先看人效空间，人效有富余才敢加薪；人效触顶还普涨，利润被吃。
