模块 / 场景：薪酬发放 — 年终奖税务
工具名称：年终奖发放与个税筹划表
适用场景：年终奖方案设计、在"单独计税"与"并入综合所得"间选更优、避开多发 1 元少拿几千的盲区
操作步骤 / 方法：
1. 确认政策：依据现行个税规定，全年一次性奖金可选择单独计税（不并入综合所得）或并入当年综合所得，二选一择优
2. 算两种方案：分别按"单独计税"和"并入综合所得"测算到手，取高者
3. 标盲区：年终奖落在"税率跳档临界点"附近时，多发 1 元税后反而少拿，需避开（如 36000、144000、300000 等临界 + 1）
4. 拆分建议：对高收入者，把部分年终奖并入综合所得可能更省；对低收入者，单独计税通常更优
5. 留痕：发放前给员工看"两种算法对比"，避免争议

模板 / 话术（可直接复制）：
```
【年终奖个税筹划速查】
单独计税公式：应纳税额 = 年终奖 ÷ 12 找税率 → 年终奖 × 税率 - 速算扣除数
盲区临界（多发1元税后倒亏）：
  36000 → 36001 多缴 2310
  144000 → 144001 多缴 13200
  300000 → 300001 多缴 13750
  420000 → 420001 多缴 19250
  660000 → 660001 多缴 30250
  960000 → 960001 多缴 88000

决策：算"单独"与"并入"两版到手，取大者；若年终奖恰在盲区+1，把多出的部分改发"工资"或"福利"更划算。
```

注意事项 / 常见坑：
- **盲区是最大的坑**：年终奖 36000 税 1080、到手 34920；发 36001 税 3390.1、到手 32610.9——**多发 1 元，到手少 2309 元**。HR 算方案务必避开临界点 +1。
- **"单独计税"不是永远最优**：高收入（综合所得已到高税率）把年终奖并入综合所得可能更省；低收入（综合所得未到起征点）单独计税更优。必须两算对比，不能一刀切。
- **一年内只能用一次**：全年一次性奖金单独计税优惠政策每纳税年度仅可用一次，分两次发会丧失优惠。
- **别为省税变违规**：把年终奖拆成"报销""借款"避税，属于虚开发票/偷逃税风险，红线不碰。
- **政策时效要注明**：个税优惠的执行期限以当年税务总局公告为准，做表时标注"依据____年公告"，过期重算。
