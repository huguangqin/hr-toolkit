模块 / 场景：薪酬体系设计 — 岗位价值量化
工具名称：岗位价值评估表（点因素法）
适用场景：搭建薪酬等级、定薪、晋升调级、岗位重组时，客观衡量岗位相对价值，终结"谁嗓门大谁工资高""老板拍脑袋"的定薪乱象
操作步骤 / 方法：
1. 选评估因素：推荐海氏（Hay）三维度（知能要求 / 解决问题 / 应负责任）或自设四因素（责任、技能、努力程度、工作条件）
2. 为每个因素划分等级并写清锚点（每级对应的典型表现），确保不同评委打分有统一标尺
3. 组建评估委员会（HR + 业务负责人 + 跨职能代表），背靠背打分后取均值
4. 汇总得分排序，按分数段划分职等（A/B/C/D…），形成"岗级—价值"映射
5. 用评估结果校准现有薪酬，拉开合理差距，把"关系户"压回价值区间

模板 / 话术（可直接复制）：
```
【岗位价值评估表 · 点因素法（精简四因素版）】
评估岗位：__________  评估日期：__________  评委：__________

因素一：应负责任（权重 40%）
  L1 执行既定流程，责任小 ......□ 1分
  L2 负责模块，有结果考核 ......□ 2分
  L3 负责部门，影响一条业务线 ..□ 3分
  L4 对全公司某职能负总责 ......□ 4分

因素二：专业技能（权重 30%）
  L1 基础操作，短期可上手 ......□ 1分
  L2 需专业训练，1-2年经验 .....□ 2分
  L3 稀缺专业，跨领域协作 ......□ 3分
  L4 行业权威，定义标准 ........□ 4分

因素三：问题解决（权重 20%）
  L1 按规则即可解决 ............□ 1分
  L2 需分析判断 ...............□ 2分
  L3 无先例，需设计新方法 .....□ 3分
  L4 定义战略问题 .............□ 4分

因素四：工作条件（权重 10%）
  L1 标准办公环境 ..............□ 1分
  L2 偶发压力/出差 ............□ 2分
  L3 高频高压/夜班 ............□ 3分
  L4 高危/极端环境 ............□ 4分

加权得分 = 责任×0.4 + 技能×0.3 + 问题×0.2 + 条件×0.1（满分4）
建议职等：≤1.5→P1  1.6-2.5→P2  2.6-3.2→P3  ≥3.3→P4
```

注意事项 / 常见坑：
- **评估的是"岗位"不是"人"**：不能因为某人能力强就把岗位定高级，否则人走岗空、薪酬失真。应描述"该岗位满编时应承担什么"，而非现任者表现。
- **评委结构要跨职能**：全是本部门人会互相抬、压竞争对手部门；至少含 1 名外部视角评委（如其他模块负责人）。
- **锚点必须写"典型行为"而非形容词**："责任大"没法打分，"对一条业务线的年度营收负责"可以打分。锚点模糊 = 打分随意 = 评估失效。
- **结果要公开职等、保密具体得分**：公开"哪些岗同级"能服众，公开个人得分易引发攀比。
- **别想一次到位**：先做核心岗位（约 30%）跑通，再扩到全岗位；每年复盘一次因素权重。
