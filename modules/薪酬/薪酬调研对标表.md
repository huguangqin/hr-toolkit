模块 / 场景：薪酬体系设计 — 市场对标
工具名称：薪酬调研与分位值对标表
适用场景：年度调薪前诊断竞争力、招聘定薪前摸市场、老板问"我们薪酬有没有竞争力"时给数据而非感觉
操作步骤 / 方法：
1. 定对标群体：同行业 + 同地区 + 同规模（人数区间）+ 直接竞对（如有渠道）
2. 定对标岗位：用"基准岗位"（JD 与市场高度一致的核心岗），避免拿自家特殊岗去比
3. 采数：第三方报告（分位 25/50/75/90）、招聘平台薪资、离职面谈、同行交流，至少取 2 个来源交叉验证
4. 算公司当前位置：用"公司该岗位中位数 ÷ 市场 P50"得出分位差
5. 出结论：低于 P25 的岗 = 流失高风险，优先补；高于 P75 的岗 = 成本冗余，控涨

模板 / 话术（可直接复制）：
```
【薪酬分位对标表】
对标范围：行业______  地区______  规模______人  数据来源：____________

岗位        市场P25  市场P50  市场P75  公司当前  公司分位  缺口动作
软件工程师   18k     22k     28k     19k       P30     补至P50
销售代表     8k      12k     18k     11k       P42     维持
财务主管     15k     19k     24k     26k       P85     冻涨
前台         5k      6k      7k      5.5k      P35     补至P45

判断线：公司分位 < P25 → 红（高危）；P25-P40 → 黄（观察）；P40-P75 → 绿（健康）；> P75 → 蓝（控）
```

注意事项 / 常见坑：
- **对标口径不一致 = 假对标**：拿一线城市的报告比三线城市薪资，或用"年包"比"月薪"，结论必然失真。先统一"地区 + 币种 + 现金/总包 + 税前"四要素。
- **用中位数不要均值**：均值会被极高分拉高，掩盖大多数人的真实位置。市场报告里的 P50 才是锚。
- **"自比自"幻觉**：只比自己去年的薪资，不比市场，会觉得"涨了不少"，其实市场涨更多，分位在掉。
- **别迷信单一报告**：一份报告可能样本偏旧或偏头部，至少 2 源；关键岗可私下找同行对 1-2 个数校准。
- **对标结果要分层用**：核心岗（难招、难替）冲 P75，通用岗守 P50，边缘岗可 P25-P40。
