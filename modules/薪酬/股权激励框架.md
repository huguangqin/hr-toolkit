模块 / 场景：长期激励 — 股权激励
工具名称：股权激励方案框架（期权 / RSU）
适用场景：留核心人才、融资前搭建期权池、用股权替代部分现金薪酬、避免"发了股权人还是走"
操作步骤 / 方法：
1. 选工具：期权（Option，未来以约定价买股）适合成长期、想低门槛绑定；RSU（限制性股票单位，达标白送股）适合已较稳、想降低风险感
2. 定池子：期权池通常占融资后 10%-20%，从创始人股里出，不稀释新员工个人
3. 设归属（Vesting）：4 年归属 + 1 年 cliff（满 1 年才归属 25%，之后按月/季归属）是标配
4. 绑退出：离职未归属部分回收；已归属部分设回购/转让规则
5. 算成本与沟通：用"未来价值"而非"现在股数"和员工讲，避免"画饼感"

模板 / 话术（可直接复制）：
```
【股权激励方案框架】
工具选择：
  期权 Option  → 行权价=近期融资价，适合未上市、成长预期强
  RSU         → 达标即授予，适合已盈利/拟上市、求稳定感

归属节奏（标准4年）：
  第0-12月：cliff，不满1年离职=0归属
  满1年：归属25%
  第13-48月：按月归属剩余75%
  满4年：100%归属

关键条款清单：
  □ 授予数量与行权价（书面）
  □ 归属条件（时间 + 绩效，如有）
  □ 离职回购价（未归属自动失效；已归属按____价回购）
  □ 上市/并购时的加速归属（单触发/双触发）
  □ 信息权（员工可查公司估值/股比）
```

注意事项 / 常见坑：
- **"归属陷阱"最常见**：发了期权但没设 cliff 或归属条件，员工干 3 个月就走还带走股权，公司肉疼。1 年 cliff + 4 年线性归属是防早跑的底线。
- **只发不说 = 白发**：员工看不懂"期权值多少钱"，觉得是画饼。必须沟通"当前估值、你的占比、退出时大概值多少"，用场景化数字讲。
- **期权池从创始人出，不从新员工稀释**：池子占融资后比例，由创始团队让渡，新入股员工按新估值进，互不稀释才公平。
- **离职回购价要事前定**：没写"以净资产/最新融资价几折回购"，人走时谈不拢，易起纠纷。书面约定优先。
- **RSU 也有税**：RSU 归属时通常按当日公允价值计个税，员工可能"股票没卖要先交税"，需提前告知或用"卖出部分股缴税"机制缓冲。
