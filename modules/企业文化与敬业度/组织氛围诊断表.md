模块 / 场景：敬业度 — 氛围诊断
工具名称：组织氛围诊断表
适用场景：从信任、公平、协作、压力等维度诊断团队氛围，定位病灶，指导管理干预，避免用敬业度一概而论。
操作步骤 / 方法：
1. 选氛围维度（信任/公平/协作/压力）。
2. 设计简短打分与开放题。
3. 按团队出氛围画像。
4. 找最差维度立项。
5. 干预后复测对比。

模板 / 话术（可直接复制）：
```
【组织氛围诊断表】
维度 | 得分(1-5) | 表现
信任 ____ 会上敢说真话吗
公平 ____ 分配升迁公吗
协作 ____ 跨队肯帮吗
压力 ____ 是否长期过载
最差维：____ 干预：____ 复测：____
```

注意事项 / 常见坑：
- 维度和敬业度混用，看不准。
- 只打分不开放，不知为何低。
- 不干预，诊断变摆设。
关联工具：员工敬业度问卷、内部沟通渠道矩阵、员工认可计划表
