模块 / 场景：文化建设 — 故事传播
工具名称：文化故事收集表
适用场景：建立机制收集和传播体现价值观的真实故事，用具体人事代替抽象口号，让文化可感可传。
操作步骤 / 方法：
1. 设定故事征集主题（对应价值观）。
2. 提供简易投稿渠道。
3. 筛选真实可验证的故事。
4. 多场景传播（周会/内刊/视频）。
5. 讲故事的人被看见被奖励。

模板 / 话术（可直接复制）：
```
【文化故事收集表】
对应价值观：____ 投稿人：____
故事主角：____ 时间：____ 场景：____
行为描述：____ 体现的价值：____
真实性核验：✓ 传播渠道：____ 奖励：____
```

注意事项 / 常见坑：
- 故事造假，反而伤信任。
- 只收集不传播，白费。
- 主角不被认可，没人再投。
