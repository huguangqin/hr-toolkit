模块 / 场景：文化建设 — 考核闭环
工具名称：文化价值观考核表
适用场景：将价值观行为纳入绩效与晋升评价，设权重与一票否决，让文化从倡导变为硬约束，避免考核只看业绩。
操作步骤 / 方法：
1. 确定价值观在考核中的权重。
2. 用行为准则打分而非印象。
3. 设红线一票否决项。
4. 上级与同事多源评价。
5. 结果连晋升与评优。

模板 / 话术（可直接复制）：
```
【文化价值观考核表】
员工：____ 周期：____
价值观权重：____% 行为打分(1-5)：____
一票否决项：____ 是否触发：✓/✗
多源评价：上级✓ 同事✓ 结果应用：晋升/评优____
```

注意事项 / 常见坑：
- 只看业绩不看价值观，劣币驱逐良币。
- 凭印象打分，主观不公。
- 否决项不清晰，难执行。
关联工具：文化行为准则对照表、文化价值观提炼表、员工认可计划表
