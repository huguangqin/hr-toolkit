模块 / 场景：文化建设 — 仪式活动
工具名称：仪式感活动设计表
适用场景：设计有文化含义的仪式（入职礼、周年、庆功、荣休），用可控成本强化归属感，避免活动脱离价值观。
操作步骤 / 方法：
1. 明确活动要传递的文化信号。
2. 选低成本高感知的形式。
3. 设计可参与的环节而非旁观。
4. 关联价值观讲故事。
5. 复盘感知与参与率。

模板 / 话术（可直接复制）：
```
【仪式感活动设计表】
活动：____ 文化信号：____ 预算：____
形式：____ 参与方式：____(非旁观)
价值锚点：____ 复盘指标：参与率/感知度____
```

注意事项 / 常见坑：
- 为办而办，与文化无关。
- 领导演员工看，无参与。
- 只烧钱无感知，白花。
