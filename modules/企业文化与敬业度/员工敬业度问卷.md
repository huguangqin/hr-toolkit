模块 / 场景：敬业度 — 测量
工具名称：员工敬业度问卷
适用场景：用结构化问卷定期测量员工敬业度，定位低分维度，驱动管理改进，避免凭感觉判断团队状态。
操作步骤 / 方法：
1. 选维度（如Q12式：我在岗、被关怀、有成长）。
2. 匿名发放，保证安全感。
3. 按团队维度出报告。
4. 低分维度立项改进。
5. 下次复测看变化。

模板 / 话术（可直接复制）：
```
【员工敬业度问卷】
维度一 我是否清楚工作要求：1-5分 ____
维度二 我是否有做好工作的资源：____分
维度三 我是否觉得被关心：____分
维度四 我是否有成长机会：____分
维度五 我的意见是否被听取：____分
团队均分：____ 最低维：____ 改进项：____
```

注意事项 / 常见坑：
- 非匿名导致不敢说真话。
- 只测不改，员工更失望。
- 维度太多填不动，回收率低。
关联工具：组织氛围诊断表、文化行为准则对照表、员工认可计划表
