模块 / 场景：敬业度 — 认可激励
工具名称：员工认可计划表
适用场景：建立及时、具体、公开的员工认可机制，用小额高频的赞赏替代只靠年终大奖，提升日常敬业度。
操作步骤 / 方法：
1. 定义可认可的价值观行为。
2. 选工具（点赞/积分/月度之星）。
3. 强调及时与具体，不泛泛夸。
4. 公开表彰并连小额奖励。
5. 追踪参与与感知。

模板 / 话术（可直接复制）：
```
【员工认可计划表】
认可行为：对齐价值观____ 工具：____
频次：实时/月度 公开渠道：____
奖励形式：积分/小礼/勋章 预算：____
参与率：____ 感知度：____ 优化：____
```

注意事项 / 常见坑：
- 只年终奖，日常无反馈。
- 夸得空泛，不知好在哪。
- 不公开，激励打折。
