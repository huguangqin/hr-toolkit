模块 / 场景：文化建设 — DEI
工具名称：多元包容推行表
适用场景：系统推进多元与包容（DEI），在招聘、晋升、文化上减少偏见，提升创新与归属感，避免形式化政治正确。
操作步骤 / 方法：
1. 明确多元维度（性别/年龄/背景等）。
2. 审查招聘晋升流程的偏见点。
3. 建包容机制（灵活/发声渠道）。
4. 设可衡量目标不喊口号。
5. 定期复盘进展。

模板 / 话术（可直接复制）：
```
【多元包容推行表】
多元维度：____ 偏见审查点：____
包容机制：灵活办公✓ 发声渠道✓
可衡量目标：____ (如女性管理占比)
进展复盘：____ 责任人：____
```

注意事项 / 常见坑：
- 只喊口号无机制，形式化。
- 只重多元忽视包容，留不住。
- 无目标不可测，难持续。
关联工具：文化行为准则对照表、员工敬业度问卷、组织氛围诊断表
