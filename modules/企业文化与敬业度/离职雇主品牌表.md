模块 / 场景：雇主品牌 — 离职管理
工具名称：离职雇主品牌表
适用场景：把离职员工作为雇主品牌资产经营，做好访谈、校友网络与回流机制，降低负面口碑、保留人才回旋余地。
操作步骤 / 方法：
1. 做真诚离职访谈，听真实原因。
2. 建 alumni 通讯录与社群。
3. 关键岗位设回流绿色通道。
4. 离职体验闭环，减少负面。
5. 定期回访看回流意愿。

模板 / 话术（可直接复制）：
```
【离职雇主品牌表】
员工：____ 离职真因：____ (保密)
校友入库：✓ 社群邀请：✓ 回流岗：____
离职体验评分：____ 负面风险：____ 回访：____
```

注意事项 / 常见坑：
- 离职即敌对方，口碑反噬。
- 不建 alumni，人才资产流失。
- 访谈走过场，真因听不到。
关联工具：离职交接清单、离职证明与社保减员表、员工敬业度问卷
