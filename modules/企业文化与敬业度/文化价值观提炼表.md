模块 / 场景：文化建设 — 价值观提炼
工具名称：文化价值观提炼表
适用场景：通过工作坊把零散的口号提炼成可共识、可传播的价值观词条，并锚定行为，避免价值观停在墙上的口号。
操作步骤 / 方法：
1. 征集高管与骨干对好行为的真实描述。
2. 聚类成3至5条价值观主题。
3. 每条配一句人话定义与反面禁区。
4. 用关键事件验证是否真信。
5. 形成词条手册全员共识。

模板 / 话术（可直接复制）：
```
【文化价值观提炼表】
价值观条数：____ (建议3-5)
条目 | 人话定义 | 正面行为 | 反面禁区
____ | ____ | ____ | ____
验证事件：____ 共识方式：____ 更新：____
```

注意事项 / 常见坑：
- 词条过多记不住，等于没有。
- 只有口号没有行为，落不了地。
- 高管不身体力行，员工当耳旁风。
