模块 / 场景：文化建设 — 新人传导
工具名称：新员工文化融入表
适用场景：在新人入职30-60-90天，分阶段传导文化价值观与行为准则，让新人尽早认同，而非只做业务培训。
操作步骤 / 方法：
1. 30天：讲清价值观与真实故事。
2. 60天：安排文化导师一对一。
3. 90天：用行为准则做融入评估。
4. 组织一次文化案例讨论。
5. 反馈融入度进HR记录。

模板 / 话术（可直接复制）：
```
【新员工文化融入表】
员工：____ 导师：____ 入职：____
30天：价值观宣讲✓ 创始人故事✓
60天：导师1v1✓ 文化疑问解答✓
90天：行为准则自评✓ 融入度：高/中/低
文化案例讨论：✓ 反馈记录：____
```

注意事项 / 常见坑：
- 只培训业务不传导文化，认同晚。
- 无导师，新人靠猜公司潜规则。
- 不评估，融入差也无人管。
关联工具：文化价值观提炼表、文化行为准则对照表、入职手续办理清单
