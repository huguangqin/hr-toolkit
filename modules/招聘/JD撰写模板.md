模块 / 场景：招聘与配置 — 岗位 JD（职位描述）撰写
工具名称：JD 撰写结构化模板
适用场景：新岗招聘、补员、JD 翻新、内部转岗发布前
操作步骤 / 方法：
1. 先定「岗位目的」一句话：这个岗为什么存在、解决什么问题。
2. 主要职责用「动词开头 + 对象 + 结果」写，3-7 条，按重要度排序。
3. 任职要求拆「硬性（学历/证书/年限/技能）」与「软性（特质/潜力）」，分别列。
4. 加「加分项」与「我们提供」，提升吸引力与筛选效率。
5. 对照动词库与禁忌词做一遍自检。

模板 / 话术（可直接复制）：
```
【岗位名称】XXX（可附职级，如 P6 / 高级）
【所属部门 / 汇报线】XXX，汇报至 XXX
【岗位目的】用一句话说明该岗位存在的价值与目标。

【主要职责】
1. 负责……，达成……（量化结果优先）
2. 主导……，提升……
3. ……

【任职要求 - 硬性】
- 学历：……
- 经验：X 年及以上……经验
- 技能：熟练使用……

【任职要求 - 软性】
- 具备……思维 / 较强的……能力
- 能适应……

【加分项】
- 有……经历 / 持有……证书

【我们提供】
- 薪酬范围：XX-XX K·月（可写区间，增强诚意）
- 成长：……
```

动词库（开头用）：负责、主导、搭建、优化、推动、统筹、分析、协同、交付、培养。
禁忌词自检：避免「985/211 优先」「男性优先」「35 岁以下」等可能涉就业歧视的表述；年限要求写「X 年及以上」而非「小于 X 岁」。

注意事项 / 常见坑：
- 职责写太虚（"参与相关工作"）→ 无法用于面试评估与考核，必须可验证。
- 要求堆砌成"超人" → 分清"必须"与"加分"，否则没人投。
- 不写薪酬区间 → 浪费双方时间，建议至少给区间。
- 直接照搬旧 JD → 岗位已变，JD 需随业务刷新。
