模块 / 场景：招聘与配置 — Offer 沟通与谈判
工具名称：Offer 谈判 Checklist
适用场景：确定意向候选人后，敲定薪酬包、提升接 Offer 率
操作步骤 / 方法：
1. 谈前准备：确认薪酬带宽、市场对标、决策人授权范围（签字费/股票/弹性等）。
2. 谈判中：先听候选人诉求，再「拆包总包」——把固定、浮动、股权、福利分开谈，用非现金筹码补缺口。
3. 谈后：发书面 Offer，明确时效与条件，限时跟进，对拒 Offer 做挽留或复盘。

模板 / 话术（可直接复制）：
```
【谈前准备】
- 内部薪酬带宽：最低__ 中位__ 最高__（对标岗位职级）
- 候选人当前总包：固定__ 浮动__ 股权__ 其他__
- 我方底线与可让步项：___________
- 已获决策人授权：□ 签字费 □ 股票 □ 职级 □ 弹性办公

【谈判中】
- 锚定：先给整体范围，再拆项细谈
- 拆包话术："我们拆开看：固定 X、年度奖金约 Y、另有 Z，整体竞争力在……"
- 非现金筹码：职级空间 / 弹性办公 / 培训预算 / 优先项目
- 倾听诉求："你最看重的是薪酬、成长、还是稳定？"

【谈后跟进】
- 书面 Offer 必备：岗位/汇报线/薪酬结构/生效日/有效期/附属条件
- 跟进时效：发出后 24h 内首次跟进，到期前 1 天提醒
- 拒 Offer 挽留：了解真实原因，判断是否有一项可调整；复盘流失点
```

注意事项 / 常见坑：
- 没授权就承诺 → 谈前必须拿到决策人底线，避免"说了不算"。
- 只谈月薪 → 候选人盯总包，拆包谈更易成交。
- Offer 有效期模糊 → 明确截止日，制造合理紧迫感。
- 忽视非现金诉求 → 很多人因"成长/弹性"留下，别只砸钱。
