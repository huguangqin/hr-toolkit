模块 / 场景：招聘与配置 — 面试反馈与候选人体验
工具名称：面试反馈与拒信模板（多场景话术 + 合规边界）
适用场景：给候选人发送面试结果/拒信、内部汇总面试反馈，兼顾体验与合规，降低舆情与歧视风险
操作步骤 / 方法：
1. 内部先出统一结论（推荐/待定/不推荐）与一句话理由。
2. 按场景选模板：未通过初面/终面、进入候补、主动撤招、超期未定。
3. 拒信只给"感谢 + 原因大类"，不给具体评分/对比他人。
4. 涉及敏感原因（如能力差距）用中性表述，不点名、不比较。
5. 入库：未过但优秀者标记人才库，留钩子。

模板 / 话术（可直接复制）：
```
【内部反馈单】（不发给候选人）
候选人：__　岗位：__　结论：□ 推荐 □ 待定 □ 不推荐
维度简评（对照评估表）：专业 __ 经验 __ 逻辑 __ 沟通 __ 文化 __ 潜力 __
一句话理由：________________________________
风险提示：□ 无 □ 诚信存疑 __ □ 红线问题 __

【拒信-初面未过】
__ 先生/女士您好，感谢您投递 __ 岗位并参加本次面试。经综合评估，本岗位与您的当前匹配度暂不充分，此次未能进入下一轮。您的资料已存入我们人才库，后续有更契合的机会会优先与您联系。祝您求职顺利！

【拒信-终面未过（更尊重版）】
__ 您好，非常感谢您投入时间完成 __ 岗位的全程面试。您在 __ 方面给我们留下深刻印象，但综合团队当前阶段的需求，我们这次遗憾未能为您提供 offer。希望保持联系，未来有机会再合作。祝职业发展的每一步都顺心。

【进入候补】
__ 您好，您已进入 __ 岗位候补名单（排名 __）。如有席位释放我们会第一时间联系；同时诚挚建议您可以同步考虑其他机会。感谢理解。

【主动撤招/超期】
__ 您好，因岗位规划调整 / 流程超期，本次 __ 岗位招聘暂时搁置，您的资料我们会保留。给您带来不便深表歉意。

【合规边界（必读）】
- 拒信不写具体落选分数、不对比"你不如某某"、不提年龄/婚育等红线原因。
- 能力差距统一用"匹配度/阶段性需求"中性表述。
- 涉及诚信存疑，内部留痕但不对候选人明示指控，避免名誉风险。
```

注意事项 / 常见坑：
- 拖着不回 → 候选人体验差、易发帖吐槽；超 5 个工作日未定主动告知进度。
- 拒信复制粘贴太冷 → 加一句具体认可点（如"您在 __ 的回答很亮眼"）。
- 把未过优秀者丢一边 → 候补/未来岗位直接捞，省 sourcing 成本。
