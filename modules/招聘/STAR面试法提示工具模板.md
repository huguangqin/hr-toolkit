模块 / 场景：招聘与配置 — 行为面试（结构化追问）
工具名称：STAR 面试法提示工具模板（面试现场可直接用的提问/记录卡）
适用场景：面试中用"情境—任务—行动—结果"逼出候选人的真实行为证据，替代"我觉得他沟通不错"式印象判断；尤其适合中高级岗位的能力深挖、跨候选人横向比较、校准会前的证据留痕。

操作步骤 / 方法：
1. 先在题库里锁定本岗 1–2 个必问的 STAR 行为题（来自《结构化面试题库》），作为所有候选人共用题，保证可比。
2. 抛出主问题后，按 S→T→A→R 顺序逐段追问，缺哪段补哪段，别让候选人只讲"我们团队"。
3. 每段追问用"当时/具体/数据"等词逼出事实，禁止接受形容词结论。
4. 现场把四段答案速记在下方「STAR 记录卡」，标注"个人贡献 vs 团队贡献"。
5. 面试后 24 小时内，把记录卡转成评估表证据，再进校准会。

模板 / 话术（可直接复制）：

【一、四段式提问主句式】（选 1–2 个维度作为必问题）
- 专业能力："讲一个你独立搞定过的最难的 __ 任务——当时什么情况？你具体做了什么？最后结果数据是多少？"
- 问题解决："说一个你从一堆乱麻里理出头绪的问题——你接手时卡在哪？你做了什么决策？带来了什么改变？"
- 团队协作/推动："讲一次你说服一个不配合的人或部门——当时矛盾是什么？你具体怎么做的？对方最后怎么响应？"
- 抗压/学习："说一个你上岗前完全不会、硬啃下来的东西——你怎么学的？用在了哪？效果如何？"

【二、逐段追问提示卡（面试现场照着念）】
S 情境（Situation）：
  → "当时是什么背景？什么时候的事？团队/业务处于什么状态？"
  → "这件事难在哪？为什么是个问题？"
T 任务（Task）：
  → "你当时被要求达成什么？你的角色和权责边界是什么？"
  → "目标是谁定的？有什么约束（时间/资源/人）？"
A 行动（Action）：★ 最关键，专盯"你"不盯"我们"
  → "你具体做了哪些动作？按时间顺序说。"
  → "这里哪些是你个人做的，哪些是团队做的？你的决定占比大概多少？"
  → "你遇到的最大卡点是什么？你怎么决策的？有没有放弃过的方案？"
R 结果（Result）：★ 必须可量化
  → "最后结果是什么？用数据说（提升 % / 节省 ¥ / 周期从 X 到 Y / 错误率下降）。"
  → "如果重来一次，你会改哪一步？为什么？"
  → "这件事里你学到的最关键一点是什么？"

注意事项 / 常见坑（假 STAR 识别）：
- 假 STAR 1「理论化」：候选人说"我一般会…/ 我觉得应该…"→ 拉回："请讲一个真实发生过的例子。"
- 假 STAR 2「团队化」：全用"我们"掩盖个人贡献 → 追问："你个人具体做了哪一步？占比多少？"
- 假 STAR 3「无结果」：故事讲得精彩但没有数据 → 追问："用数字说最后结果是多少？"
- 假 STAR 4「流水账」：只讲做了什么，没讲为什么这么决策 → 追问："你为什么选这个方案而不是那个？"
- 别用假设题（"你会怎么处理"）替代行为题（"你过去怎么处理的"）——前者测的是口才，后者 predictability 高得多。
