模块 / 场景：招聘与配置 — 面试邀约与安排
工具名称：面试邀约与安排确认模板（电话/微信话术 + 确认清单）
适用场景：HR/招聘专员向候选人发出面试邀请、确认时间地点、发送提醒，降低"放鸽子"与信息不对称
操作步骤 / 方法：
1. 邀约前准备：确认岗位、面试官、时间窗、地点/线上链接、需带材料。
2. 电话/语音邀约：自报家门 → 确认方便说话 → 介绍公司与岗位 → 给时间选项 → 确认方式。
3. 微信/短信补发书面确认：时间、地点、路线、联系人、需带材料。
4. 面试前 1 天发送提醒（含天气/交通提示）。
5. 候补机制：对未确认者设截止时间，超时释放名额给候补。

模板 / 话术（可直接复制）：
```
【电话邀约话术】
"您好，请问是 __ 先生/女士吗？我是 __ 公司 HR __，打扰了。看到您之前投递 / 我们关注到您在 __ 的履历，想邀请您来聊聊 __ 岗位，方便耽误您两分钟吗？
……我们初步想约 __（日期）__（上午/下午）__（具体时间），线上腾讯会议 / 到我们 __ 地址，您看这个时间方便吗？不方便的话我这边还有 __ 和 __ 两个时段可选。
……好的，稍后我把具体时间、地址和需要带的材料用微信发您。面试联系人是我，__，有任何变动随时找我。期待和您聊！"

【微信书面确认】
【面试邀约】__ 先生/女士您好，已和您电话确认 __ 岗位面试，详情如下：
⏰ 时间：__ 年 __ 月 __ 日（周 _）__:__
📍 地点：__（线上：会议号/链接 __，密码 __）
🧭 路线：地铁 __ 线 __ 站 __ 口出，步行 __ 分钟；开车导航搜 "__"
👔 需带：身份证、简历 __ 份、作品集/证书（如适用）、笔
📞 联系人：__（__）面试前如有变动请提前告知，谢谢！

【面试前 1 天提醒】
明天 __:__ 面试，记得带 __；如迟到/改期请尽早联系我。祝顺利！
```

注意事项 / 常见坑：
- 只给 2 个具体时间选项，别问"您什么时候方便"（易石沉大海）。
- 书面确认必须含路线 + 联系人，可显著降低爽约率。
- 候选人已入职竞品/婉拒 → 礼貌结束，记入人才库备注，留钩子。
- 薪资数字口头不说区间，统一"以终面沟通 / Offer 为准"，避免哄抬或吓退。
