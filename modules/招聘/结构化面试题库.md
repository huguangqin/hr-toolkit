模块 / 场景：招聘与配置 — 结构化提问
工具名称：结构化面试题库（按能力维度 + STAR 追问）
适用场景：面试前按维度抽取题目，保证不同候选人"被问同样的问题、按同样尺度评"，结果可比
操作步骤 / 方法：
1. 锁定本岗 6 个考察维度（来自 JD）。
2. 每维度准备 2-3 道行为题（问过去事实，不问假设）。
3. 每题配 STAR 追问（情境/任务/行动/结果）。
4. 现场按"行为题 → STAR 追问 → 证据记录"走。
5. 评分对照锚定，禁止形容词结论。

模板 / 话术（可直接复制）：
```
【专业能力】
- "讲一个你独立搞定的最难 __ 任务，你具体做了什么？"
  → 追问：卡点是什么？你如何决策？最终指标/数据？
- "你最自豪的一个专业成果，它难在哪？你贡献占比？"

【经验匹配】
- "你过往哪段经历和本岗最像？哪些地方不像？"
  → 追问：不像的部分你打算怎么补？

【逻辑思维与问题解决】
- "描述一个你从混乱里理出头绪的问题，你如何拆解？"
  → 追问：如果数据只有一半，你会先验证什么？

【沟通表达】
- "讲一次你劝说一个不配合的人，怎么做的？"
  → 追问：对方为什么抗拒？你改了什么说法？

【文化适配】
- "你最受不了哪种团队氛围？为什么？"
  → 追问：上一家你最认同的一点是什么？

【潜力/学习力】
- "过去一年你学的最有用的新东西，怎么学的？"
  → 追问：学完用在了哪？效果？

【STAR 追问万能句】
"当时情况是？— 你具体负责哪块？— 你做了什么决定/动作？— 结果数据是多少？— 如果重来你会改哪一步？"
```

注意事项 / 常见坑：
- 问"假设题"（"你会怎么…"）→ 改成"过去做过的最像的事"，更能预测未来行为。
- 同一维度换着问 → 保留题库，但每候选人至少 1 道统一题保可比。
- 只记结论不记事例 → 必须写证据，否则校准会无法复核。

关联工具：面试评估表（维度与锚定来源）、面试官对齐清单（分工依据）
