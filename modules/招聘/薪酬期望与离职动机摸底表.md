模块 / 场景：招聘与配置 — 薪酬与动机摸底
工具名称：薪酬期望与离职动机摸底表（话术 + 记录栏）
适用场景：面试中/终面前摸清候选人薪资期望、离职动机、到岗时间，避免谈 Offer 阶段崩盘
操作步骤 / 方法：
1. 初面聊动机与期望区间（不报具体数）。
2. 复面/终面用"区间 + 构成"摸清底线与弹性。
3. 记录当前薪资构成（底/奖/股/补贴）与期望涨幅。
4. 探离职真实原因与决策人（家人/现东家挽留？）。
5. 确认到岗时间与竞业/保密约束。

模板 / 话术（可直接复制）：
```
候选人：__　岗位：__　面谈轮次：__　日期：__

【当前薪酬构成】（务必分项问）
- 月固定：__　绩效/奖金（年）：__　股票/期权：__　补贴：__　其他：__
- 当前总现金（年）：__　上次调薪：__　下次调薪窗口：__

【期望】
- 期望月薪区间：__　最低可接受：__　涨幅底线：__%
- 看重的非现金项（多选）：□ 成长 □ 稳定 □ 团队 □ 弹性 □ 股权 □ 地点

【离职动机】
- 想离开现东家的主因：________________________________
- 最能留住你的 3 件事：① __ ② __ ③ __
- 是否有家人/现东家挽留：□ 是 __　□ 否

【到岗与约束】
- 最快到岗：__　离职周期：__　竞业/保密协议：□ 有 __　□ 无
- 同时面试的其他公司/阶段：________________________________

【话术】
- 引薪："方便了解下您现在的薪酬构成吗？我们内部做对比用，不会外传。"（先问构成再问期望，更容易开口）
- 期望："您对下一份的薪酬大致是什么预期？有没有一个心里最低线？"（要"底线"比要"期望"更真实）
- 动机："如果有个各方面都不错但 __（某短板）的 offer，您会怎么选？"（探真实排序）
```

注意事项 / 常见坑：
- 初面就报公司薪资区间 → 易把人吓跑或哄抬；先摸底再谈。
- 只问期望不记构成 → 谈 Offer 时不知道对方底线，易崩。
- 不问竞业/保密 → 入职后爆雷；终面前必须确认。
- 口头承诺不写 → 所有关键数字让候选人书面确认（Offer 环节）。
