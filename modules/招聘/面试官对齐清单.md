模块 / 场景：招聘与配置 — 面试官协同
工具名称：面试官对齐清单（Interview Briefing Checklist）
适用场景：多面试官串行/并行面试前，HR 与用人经理对齐考察维度、分工与红线，避免各打各的、标准不一
操作步骤 / 方法：
1. 发 JD + 评估表给每位面试官，明确本岗"看重什么"（权重）。
2. 分配维度：每人主考 1-2 个维度，避免重复问、漏问。
3. 对齐行为锚定与评分尺度（参考面试评估表）。
4. 划禁问红线（见注意事项）。
5. 定流程：时长、顺序、谁收尾、谁主导校准会。

模板 / 话术（可直接复制）：
```
【面试前对齐｜请面试官面试前 30 min 完成】
- 岗位：__　职级：__　招聘紧急度：__　HC 类型：新招 / 替补
- 本岗 Top3 看重（按权重）：① __ ② __ ③ __
- 你的主考维度：__　协考维度：__
- 你这场时长：__ min；建议追问方式：STAR
- 必问的统一题（所有人问，便于横向比）：
  ① "请用一件事说明你 __"
  ② "你最想在这岗做出什么不同？"
- 禁问红线（一律不问）：年龄 / 婚育 / 户籍 / 信仰 / 疾病 / 家庭计划 / 前公司具体薪酬 / 竞业细节
- 评分提交：面试后 24h 内独立填评估表，先写后聊
- 收尾人：__（负责答疑 + 下一步时间线告知）
```

注意事项 / 常见坑：
- 没对齐就开面 → 各面试官标准不一，结论不可比。
- 所有人都问同一"感觉"题 → 浪费时间且无证据；统一必问题保可比。
- 面试官抢话/带节奏 → 指定一人主导校准会，先收表再讨论。
- 红线问题一旦问出口，轻则候选人体验差，重则就业歧视风险。

关联工具：面试评估表（评分尺度来源）、结构化面试题库（抽题依据）
