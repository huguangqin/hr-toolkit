模块 / 场景：人才发展 — 师徒带教
工具名称：导师制（师徒制）运行表
适用场景：新人融入慢、关键经验只攥在少数人手里、高潜没人带。用结构化师徒机制把"隐性经验"显性传递，避免"放养式"培养（师傅忙就忘了带）
操作步骤 / 方法：
1. **选师徒**：师傅需绩效≥B、有带教意愿、在岗稳定；师徒尽量跨汇报线（直属上级当师傅易变"派活"）。
2. **签契约**：明确周期（通常 3-6 月）、频次（每周≥1次）、目标（3 项可验收能力），双方+上级签字。
3. **定内容地图**：按"文化融入 / 业务知识 / 实操技能 / 人际网络"四块拆解带教清单，逐月解锁。
4. **月度复盘**：师傅填观察记录，HR 抽查，避免形式化。
5. **双向激励**：徒弟出师 + 师傅带教工时折算绩效/课酬，双向有动力。

注意事项 / 常见坑：
- **师傅=直属上级**：极易变"派活+背锅"，徒弟不敢问傻问题。优先跨线选人。
- **只签不跟进**：契约签完没人查，三月后"啥也没带"。HR 月度抽查 + 出师评估兜底。
- **师傅无激励**：纯靠觉悟，忙起来就弃。带教工时折算绩效或课酬，成本远低于外训。
- **目标不可验收**："提升能力"无法评估。必须写"能独立完成X，错误率<Y%"。
