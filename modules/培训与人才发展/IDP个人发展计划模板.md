模块 / 场景：人才发展 — 个人成长
工具名称：IDP 个人发展计划模板（Individual Development Plan）
适用场景：高潜员工、晋升候选、绩效改进期的员工，把"想成长"变成"有路径"。避免发展计划写成"多参加培训"这种空话，或只有公司视角没有员工意愿
操作步骤 / 方法：
1. **现状盘点**：当前能力 vs 目标岗位/当前角色要求的差距（用能力模型或上级反馈）。
2. **定发展目标**：1 年内可达，分"专业力/领导力/经历"三类，员工自提 + 上级对齐。
3. **选发展方式**：70-20-10 法则——70% 在岗挑战（轮岗/牵头项目）、20% 人际学习（导师/反馈）、10% 培训课程。别只堆课。
4. **写具体动作+时间表**：每条目标对应 1-2 个动作、责任人、截止日、验收证据。
5. **季度回顾**：上级与员工双签字复盘，动态调整（业务变了目标也要变）。

模板 / 话术（可直接复制）：
```
【IDP 个人发展计划】
员工：__________  部门：__________  周期：____至____  直线上级：__________

一、现状与目标差距
目标角色/要求：________________________
当前强项：________________________
关键差距（≤3）：
1. __________  2. __________  3. __________

二、发展目标（SMART，1年内）
目标1（专业力）：________________  验收：________________
目标2（领导力）：________________  验收：________________
目标3（经历）：________________    验收：________________

三、发展方式（70-20-10）
目标 | 70%在岗挑战 | 20%人际学习 | 10%培训 | 截止日 | 证据
____|___________|___________|_____|_____|_____
____|___________|___________|_____|_____|_____

四、季度回顾
Q__ 进展：__________ 阻碍：__________ 调整：__________
员工签字：____  上级签字：____  日期：____
```

注意事项 / 常见坑：
- **10% 培训顶了 100%**：把 IDP 写成"上课清单"，脱离真实成长。牢记 70-20-10，重挑战性任务。
- **只有公司视角没员工意愿**：员工不想做的不了了之。目标要员工自提、上级对齐，双向认账。
- **写完不回顾**：IDP 进档案吃灰。季度回顾 + 双签字，否则等于没做。
- **差距来自上级主观**：用数据/行为事件支撑差距，避免"我觉得你不行"引发抵触。
