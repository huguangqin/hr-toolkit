# 协商 vs 诉讼 决策框架与敞口测算

> 评分告诉你"赢面多大"，这一篇告诉你"打还是谈、底线多少钱"。核心是把情绪和原则，翻译成一个可比较的数字。

## 一、先算"如果打，要花/赔多少"（敞口）

### 1. 经济补偿金与赔偿基数

| 项目 | 公式 | 备注 |
|---|---|---|
| 工作年限 `N` | 每满1年=1个月；6个月–1年=1个月；<6个月=0.5个月 | 上限封顶：基数 > 当地社平3倍时按3倍计 |
| 月平均工资基数 | 解除前12个月应得平均工资 | 含奖金、津贴；超社平3倍封顶 |
| 协商解除补偿 | `N` 或 `N+1` | 协商可谈，无强制+1 |
| 违法解除赔偿 | `2N` | 公司败诉且选赔钱不选恢复劳动关系时 |
| 代通知金 | `+1个月` | 未提前30天通知时 |

### 2. 常见附加敞口（易被漏算）

| 项目 | 估算口径 | 说明 |
|---|---|---|
| 未休年假工资 | `天数 × 日工资 × 2`（额外200%） | 历史累积，离职时集中爆发 |
| 加班费欠付 | 按考勤倒算，争议大 | 京沪粤举证规则不同（见 local-adjudication） |
| 社保/公积金补缴 | `（实发−申报基数）差 × 比例 × 欠缴月数` | 历史欠缴，仲裁/稽查均可触发 |
| 股权/长期激励追回或作废 | 个案卷宗估算 | RSU/PSU 取消索赔常不在补偿台账内 |
| 律师费/仲裁成本 | 个案 | 部分城市支持由败诉方承担合理部分 |
| 管理时间 + 声誉 | 折算 | 高管案、群体案尤甚 |

> **输出敞口区间 [保守, 悲观]**：保守 = 仅法定 N/2N+年假；悲观 = 叠加补缴+加班+股权+管理费。脚本 `score_case.py` 算保守部分，其余标注"个案估算"。

## 二、诉讼期望值（EV）

```
EV(诉讼) = P(不利) × 不利成本均值  +  P(维持) × 维持成本(律师费+管理时间)
```

- `P(不利)` 取自风险评分的概率区间中值
- `不利成本均值` = 悲观敞口的中值
- `维持成本` = 即便赢了也要花的律师费+管理时间（非零）

**关键直觉**：只要 `EV(诉讼) < 员工要价`，"谈"在纯金钱上就不亏；但还要叠加下面两类的非金钱因素。

## 三、协商上限（ceiling）

```
协商上限 = EV(诉讼)  +  确定性溢价(建议 15%–30%)  +  管理费(声誉/时间折算)
```

- **确定性溢价**：把"赢了但耗时耗力、仍有概率输"折算成一次性买断的溢价
- **比价决策**：
  - 员工要价 ≤ 协商上限 → **建议协商**（省钱省心）
  - 员工要价 > 协商上限 → 进入"是否值得打"评估

## 四、必谈 / 必打 决策树

```
是否触发红旗（证据C/D、保护期、当地不利、已委托律师）？
 ├─ 是 → 不低价硬解，先消除红旗或转协商路径
 └─ 否 ↓
员工要价 ≤ 协商上限？
 ├─ 是 → 协商结案（优先）
 └─ 否 ↓
是否属于以下"必打"情形？
 ├─ 原则性案件（制度权威、红线捍卫）
 ├─ 群体性/示范效应（不立标杆后患更大）
 ├─ 证据充分且员工主张明显无理
 └─ 是 → 即便贵也打，计入"管理投资"
        否 → 重新谈 / 找折中（降级处分、延长协商期）
```

## 五、谈判锚点建议

- **锚定法定下限**：先抛 `N`（而非 2N），把空间留给升级
- **用"程序补正"换"金额下修"**：若证据偏弱，宁可多给钱换快速了结，不赌裁决
- **设置有效期**：协商方案带时效，避免员工借机拖延
- **留书面**：所有协商以《协商解除协议》闭环，含"双方再无争议"条款

> 所有金额测算为管理参考，实际补偿以法务合规口径及最新社平工资为准；涉及封顶基数须按解除时当地上一年度社平工资3倍执行。
