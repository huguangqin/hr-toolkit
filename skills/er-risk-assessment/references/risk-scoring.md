# 风险评分模型（7 维）

> 模型目标：把"这个案子会不会输、输多少"从定性感觉变成可比较的分数。分数是**风险提示工具**，不是胜诉保证；最终以法务意见为准。

## 一、因子与计分

每个因子按"风险贡献"打 0–3 分（分越高越危险），乘权重后汇总，归一化到 0–100。

| 因子 | 取值 → 风险分 | 权重 | 说明 |
|---|---|---|---|
| **证据链完整度** `evidence_grade` | A=0 / B=1 / C=2 / D=3 | ×3 | 最核心。C/D 级解除风险陡增 |
| **程序合规度** `procedure_compliant` | 合规=0 / 部分=2 / 不合规=3 | ×2 | 工会通知、送达、民主程序 |
| **法定保护期** `protected_period` | 无=0 / 不确定=2 / 在保护期=3 | ×3 | 医疗/孕产/工伤/三期零容忍 |
| **员工法律准备** `employee_lawyered` | 无=0 / 威胁=1 / 已委托=3 | ×2 | 已委托律师显著提升对抗性 |
| **当地裁判口径** `local_tendency` | 未知=1 / 有利=0 / 不利=3 | ×2 | 默认未知，须标 `待核实` |
| **拟处置类型** `action_type` | 协商=0 / 调岗=1 / PIP=1 / 违纪处分=2 / 过失性解除=3 | ×2 | 过失性解除天然诉讼风险最高 |
| **金额量级** `amount_involved` | 小(<社平3倍年包)=0 / 中=1 / 大(高管/高基数)=2 | ×1 | 仅作轻度修正，不算主因 |

**满分** = 3×3 + 3×2 + 3×3 + 3×2 + 3×2 + 3×2 + 2×1 = 44
**风险分** = 实际得分 ÷ 44 × 100（取整）

## 二、概率区间映射

风险分 → "公司不利结果（败诉或部分败诉）概率"区间：

| 风险分 | 等级 | 公司不利概率区间 | 含义 |
|---|---|---|---|
| ≥ 70 | 🔴 高 | 70%–90% | 大概率输，优先谈或补正 |
| 45–69 | 🟠 中高 | 45%–70% | 五五开偏输，需强化证据/程序 |
| 25–44 | 🟡 中 | 25%–45% | 略占优，可打可谈 |
| < 25 | 🟢 低 | < 25% | 胜算高，按标准流程推进 |

> 概率区间是**区间**不是点估计。输入因子越模糊（尤其 `local_tendency=未知`），区间应拉得更宽，并在报告中显式标注"因当地口径未核实，区间偏保守"。

## 三、红旗信号（覆盖分数，直接升级）

满足任一，**不论分数高低**，在报告里标 ⚠️ 并建议"暂停/升级法务"：

- 🚩 证据链 = D 级（无实质证据）
- 🚩 程序 = 不合规（未通知工会/未送达）
- 🚩 法定保护期 = 在保护期
- 🚩 员工 = 已委托律师 且 处置为过失性解除
- 🚩 `local_tendency` = 不利 且 处置为过失性解除

红旗案件的处理原则：**不进入"低成本协商"测算，先解决红旗本身**（补证据、补程序、等保护期结束、或改协商路径）。

## 四、使用纪律

- 评分前先确认 `evidence_grade` 用的是原始载体证据，不是截图（见 `er-case-communication` 电子证据要求）。
- `local_tendency` 未核实时，默认填 `未知`，由法务补全后再定稿。
- 同一案件在处置前、谈话后、仲裁前可各评一次，对比分数变化验证策略是否有效。
- 分数仅用于内部决策排序，**不得作为对外告知员工的依据**。
