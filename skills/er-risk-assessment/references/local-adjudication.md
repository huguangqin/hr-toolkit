# 地方裁判口径差异提示（必标 `待核实`）

> 同一部《劳动合同法》，京、沪、粤（广深常有差异）的裁判口径可能相反。**评分模型里的 `local_tendency` 默认 `未知`，本文件仅做"去核实什么"的清单，不替代当地司法实践。**

## 一、高频分化点（去核实清单）

| 议题 | 常见分化 | 核实动作 |
|---|---|---|
| **加班费举证责任** | 北京偏公司举证考勤；广东部分要求员工初步举证 | 查当地高院纪要/仲裁委口径 |
| **竞业限制** | 补偿下限、违约救济、启动条件各地不一 | 查当地规定+最新案例 |
| **违法解除赔偿 vs 恢复劳动关系** | 上海倾向判恢复；北京更接受 2N | 查当地判例倾向 |
| **年终奖/绩效奖金** | 离职员工是否按比例发，口径不一 | 查公司所在地判例 |
| **医疗期计算** | 工龄对应医疗期月数，细节有差 | 查当地规定 |
| **未签劳动合同二倍工资** | 起算、封顶、特殊情形认定 | 查当地口径 |
| **劳务派遣/外包认定** | 逆向派遣、混同用工认定宽严不一 | 查当地案例 |
| **社保补缴时效** | 稽查 vs 仲裁受理范围不同 | 查当地社保中心口径 |

## 二、使用规则

1. **未核实不填"有利/不利"**。拿不准一律 `未知`，评分按保守（未知=1分）处理。
2. **按公司用工布局城市分别核实**。多地用工时，同一案件可能因履行地不同结论相反，须标注履行地。
3. **新口径优先于旧纪要**。高院纪要可能被后续指导案例或新规覆盖，核实时间应晚于案件评估时间。
4. **联动 `er-legal-monitor`**。发现当地口径变化，回流到法规监控台账，避免下次重复核实。

## 三、核实来源（脱敏后内部留存）

- 当地高级人民法院官网"审判业务"栏目
- 当地劳动人事争议仲裁委员会发布的裁量指引
- 主流律所该地办公室的劳动法年度观察
- 已决类案的裁判文书（中国裁判文书网，注意隐名）

> 本文件是"提醒去核实"，不是"答案"。任何 `local_tendency` 的非未知取值，报告里必须附核实来源与日期。
