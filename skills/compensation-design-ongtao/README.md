# compensation-design-ongtao

> 翁涛《薪酬总监修炼笔记——我在世界500强公司管薪酬》方法论蒸馏而成的**可一步步执行的薪酬设计 Skill**。

不是读书笔记，是一份能直接拿来出方案的作业流程：从职位评估、薪酬调研、结构设计，到调薪矩阵与奖金固浮比，按 Step 0–8 跑完一遍就能产出可交付的薪酬方案。

## 为什么再做一个

市面上薪酬设计资料分两类：西方通用框架（Milkovich / Hay / 美世 / WTW）偏理论，落地要自己翻译；国内实操文章又多是碎片经验，缺数字。

这个 Skill 补的是**中间那段可直接落地的中国外企实操口径**——尤其是别的资料里找不到的**书内真实调薪矩阵与算法**。

## 核心内容

**两根支柱**：内部公平性（职位体系 + 职位评估）× 外部竞争性（薪酬调研）。

**关键指标**（含书内定义）：
- 薪酬比率 CR = 员工工资 ÷ 该级别中点值（外企称 Compare-Ratio）
- 薪酬渗透率 = (员工工资 − 最小值) ÷ (最大值 − 最小值)
- 外部竞争比率 = 内部员工工资 ÷ 外部市场工资

**调薪矩阵（书内真实数值）**：

表 5-19 区间版（推荐实操，横轴 CR 三档 × 纵轴绩效五档，每格为区间）：

| 绩效 \ CR | CR<80% | 80%–120% | CR>120% |
|---|---|---|---|
| S（最优） | 13%–15% | 11%–13% | 9%–11% |
| 4 | 11%–13% | 9%–11% | 7%–9% |
| 3 | 7%–9% | 6.5%–7.5% | 3%–5% |
| 2 | 3%–5% | 1%–3% | 0% |
| 1（最差） | 0% | 0% | 0% |

表 5-17 单值版（某公司案例，预算 8%；横轴薪酬区间四档：绿圈 / 第一二区间 / 第三四区间 / 红圈）：

| 绩效 \ 区间 | 绿圈 | 第一、二区间 | 第三、四区间 | 红圈 |
|---|---|---|---|---|
| 优秀 | 17% | 14% | 11% | 7% |
| 良好 | 14% | 11% | 8% | 4% |
| 中等 | 11% | 8% | 5% | 2% |
| 较差 | 5% | 3% | 0% | 0% |
| 不能接受 | 0% | 0% | 0% | 0% |

**矩阵四步加权算法**：
1. 算两组分布比例：薪酬区间占比 a1–a4、绩效结果占比 b1–b5（各和 100%）
2. 每格建议值 × a × b 加权求和 → 总体加权平均调薪率
3. 对齐预算（加权平均率 ≈ 或略小于调薪预算）
4. 用**真实员工薪酬数据验算**（坑：高绩效员工往往工资也高，会吃掉预算）

**其它**：职位评估（含某公司在用的自建因素实例：任职资格 / 角色定位 / 个人能力）、薪酬结构分析（级差随层级加大、重叠度要适度）、奖金固浮比与销售激励（销售奖金约占年度总现金 50%、行政后勤约 30%）。

## 使用

触发词：薪酬设计 / 薪酬体系 / 调薪矩阵 / 职级薪酬架构 / 职位评估 / 薪酬调研 / 级差 / compa-ratio / 固浮比 / 薪酬诊断 …

示例：

- 「帮我设计销售序列的薪酬架构」
- 「出一份年度调薪矩阵，预算 8%」
- 「诊断一下我们有没有新老倒挂」

## 边界（不适用）

- 劳动法律合规审查
- 个税、股权激励税务筹划（只给原则，不替代专业意见）
- 个人求职谈薪、算单个员工工资条

书里方法论偏外企视角，小公司可走敏捷宽带 + 市场对标的轻量版，不必全量照搬。
