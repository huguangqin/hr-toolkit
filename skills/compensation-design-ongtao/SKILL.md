# 薪酬设计实操 Skill

> 本 Skill 由《薪酬总监修炼笔记》（翁涛）的方法论蒸馏而来，定位为**可一步步执行的薪酬设计工作流**。翁涛的薪酬管理框架只有两根支柱——**内部公平性**（靠职位体系与职位评估）与**外部竞争性**（靠薪酬调研）。所有薪酬动作都围绕"在内部公平和外部竞争之间求得平衡"展开。

## A2 — 何时用 / 何时不用（触发边界）

**启用情境（语言信号）：**
- "我们要设计/重做一套薪酬体系""帮我写个薪酬方案""搭建薪酬架构"
- "做职位评估/定岗定级""职位级别怎么分宽窄"
- "薪酬调研报告怎么看""市场分位怎么对标"
- "年度调薪怎么做""调薪矩阵怎么算""compa-ratio 怎么用"
- "销售激励/奖金方案怎么设计""固浮比怎么定"
- "我们薪酬有没有新老倒挂/级差不合理"（薪酬诊断）

**不要启用（反场景）：**
- 问劳动法合规、裁员赔偿、社保基数 → 那是合规问题，不是设计问题
- 问个税筹划、股权激励的税务架构 → 超出本书范畴，只给原则不替代专业意见
- 问"我该怎么跟老板谈涨薪" → 个人谈薪，不是体系设计
- 单纯计算某员工当月应发工资 → 这是薪酬核算，不是薪酬设计

## 核心框架：薪酬管理的两根支柱与全流程

翁涛全书逻辑是一棵倒过来的树：

```
              薪酬战略 (领先/跟随/滞后)
                    │
    ┌───────────────┴───────────────┐
  内部公平性                        外部竞争性
  (职位体系)                        (薪酬调研)
  职位分析→职位说明书→职位评估      选报告→解读数据→市场中位线
  →职位级别→职位族群
                    │
              薪酬结构设计
         (级宽/级差/重叠度/中点)
                    │
              薪酬架构搭建
        (内部法/外部法/结合法/点对点)
                    │
    ┌───────────────┴───────────────┐
   调薪(预算+调薪矩阵)              激励(奖金/销售激励PMT)
                    │
               薪酬沟通
```

**一句话**：先靠职位体系把"内部谁比谁值钱"定清楚（内部公平），再靠薪酬调研把"我们在市场上贵不贵"定清楚（外部竞争），然后用这两头的数据把薪酬结构和架构搭起来，最后用调薪矩阵和激励方案去分配，并沟通到位。

## 数学工具包（翁涛反复强调，务必先掌握）

薪酬设计不是拍脑袋，是算出来的。先把这些指标刻进脑子：

| 指标 | 定义 / 公式 | 用途 |
|---|---|---|
| **分位数 (Percentile)** | 把薪资从小到大排，P50=中位、P25/P75=四分位 | 看市场定位、看内部离散，比平均数更抗极端值 |
| **回归线 (Regression)** | 用职位级别(或点数)对薪资做回归，得"市场线/内部线" | 判断薪资随级别增长是否合理、找偏离点 |
| **薪酬比率 (CR / Compa-ratio)** | 员工实际薪资 ÷ 该级别中点 〔书内明确定义，外企称 CR=Compare-Ratio〕 | <1 偏低、=1 居中、>1 偏高；调薪矩阵的核心横轴 |
| **薪酬渗透率 (Penetration)** | (员工薪资−最小值) ÷ (最大值−最小值) 〔书内明确定义〕 | 看员工在带宽里的位置，0=最低、1=最高 |
| **外部竞争比率** | 内部员工工资 ÷ 外部市场工资（可选手分位/均值）〔书内明确定义〕 | >1 高于市场、=1 持平、<1 低于市场；做外部竞争力分析 |
| **级宽 (Range Width)** 〔**行业通用，书内未给公式，仅图示**〕 | (最大值−最小值) ÷ 最小值 ×100%（常见写法） | 基层宽(50–80%)、高层窄(20–40%)，级别越高级宽越窄 |
| **级差 (Step Diff)** 〔**行业通用，书内未给公式**〕 | 相邻级别中点之差 ÷ 下级中点 ×100% | 书内原则：层级越高、级差越大（无标准值）；通用 15–30% |
| **重叠度 (Overlap)** 〔**行业通用，书内仅图示三形态**〕 | 相邻级别薪资区间重叠的比例 | 书内三形态：无重叠/过度重叠/适度重叠；通用基层高重叠便于轮岗 |

**关键直觉**：不要用"平均数"分析薪酬问题，要用"竞争性指标"（分位、compa-ratio、渗透率）。平均数会被高管薪资拉偏，掩盖内部的倒挂和离散。

## 逐步执行 SOP

### Step 0 — 薪酬诊断（先摸清楚现状，别上来就设计）

目标：用数据证明"现在有什么问题"，让后面的设计有靶子。

1. **内部公平性诊断**
   - 拉全员薪资 × 职位级别，算每个级别的 compa-ratio 分布、渗透率分布
   - 找"新老倒挂"：同工龄短的人比老员工高（回归线斜率异常）
   - 找"同级离散"：同一级别薪资跨度过大（说明没管控）
2. **外部竞争性诊断**
   - 用最近一次薪酬调研，算公司整体 P50 对标市场的分位
   - 标出哪些级别"市场竞争力不足"（compa-ratio < 0.9 且市场分位 < P50）
3. **产出**：一份《薪酬现状诊断表》——列出问题级别、问题类型、严重程度。
   - **完成标准**：能回答"我们现在薪酬最大的 3 个问题是什么"。

> 判停点：若诊断显示问题集中在某一两个级别，可只针对这些级别做局部重设计，不必全量重搭。

### Step 1 — 职位体系搭建（内部公平的底座）

没有干净的职位体系，薪酬就是空中楼阁。

1. **职位分析**：用访谈法（书里给了访谈提问模板），搞清楚每个职位"做什么、为什么、需要什么"
2. **职位说明书**：写清职位目的、职责、任职要求（注意用 action verb）
3. **职位评估**：三选一
   - **定量自建法**：公司自己定义评估因素，打分→得出点数→映射级别。书里"某公司自建体系"实例用了 **3 个维度 / 7 个要素**：
     - **任职资格**（学历背景、经验积累）
     - **角色定位**（沟通用途、地域划分、职位类别）
     - **个人能力**（学习能力、工作能力）
     - 逻辑：设维度 → 按重要性赋权重 → 各维度分数累加 = 总分 → 按分数段划层级（要素计点法）
   - **Hay 海氏**：知能/解决问题/应负责任 三维度
   - **Mercer 美世**：强调/沟通/创新/知识 等维度
   - 小公司用定量自建法够用；想对标市场用美世/Hay
   - **注意（书里强调）**：评估是**判断性、对比性、层级性、以工作为中心**的——只看职责，不考任职者学历/业绩/经验
4. **职位级别 (Grade)**：评估点数 → 归级。决定"级别宽窄"：级别多=窄（每级差异小、晋升频繁），级别少=宽（每级差异大、管控粗）
5. **职位族群 (Job Family)**：把相似职位归族（如 研发族/销售族/职能族），方便做族群内对标

- **完成标准**：每个职位都有级别、有说明书、有评估点数，能画出自家"级别阶梯"。

### Step 2 — 薪酬调研（外部竞争的数据源）

1. **选报告类型**
   - 标准报告（买现成的，便宜，但职位匹配可能不精准）
   - 定制化调研（自己组局邀请同行，贵但对口）
   - 自检：样本量、行业匹配、职位匹配度够不够
2. **解读数据**
   - 看每个级别/职位的市场 P25/P50/P75
   - 用回归得到"市场中位线"（market line）
3. **避坑**：别只看 P50，要看你公司战略定位该对标哪个分位（见 Step 3 薪酬战略）

- **完成标准**：拿到"市场中位线"和每个级别的市场分位值。

### Step 3 — 薪酬战略制定

回答一个根本问题：**我们愿意在市场薪酬曲线上站在什么位置？**
- **领先型**：对标 P75+（抢人、留人，成本高）
- **跟随型**：对标 P50（大多数公司的选择）
- **滞后型**：对标 P25（成本敏感，需靠非现金补偿补足）

**★ 战略"一致性"（翁涛强调，原蒸馏遗漏）**：薪酬战略必须与公司经营战略、人力资源管理战略**对齐**，分三层一致——
- 公司层面：业务战略（如"从卖产品转向卖解决方案"）
- 人力资源管理层面：人才战略（如"吸引培养保留解决方案人才"）
- 薪酬管理层面：薪酬政策（如"薪酬水平达市场中位值、优秀员工达75分位；薪酬=固定工资+可变工资+福利"）
> 书里的示例原话：薪酬管理层面要确保"优秀员工达到75分位值"，且固定/可变/福利比例参考行业实践。

把战略写一句话："我们对核心岗位采用领先型、对支持岗位采用跟随型，且三层战略保持一致。" 这句话决定后面所有中点怎么定。

- **完成标准**：有明确的"分岗位分策略"定位 + 三层一致性说明，被业务负责人认可。

### Step 4 — 薪酬结构设计（定义每个级别的"薪资区间"）

这是把"级别"变成"钱"的关键一步。每个级别设计一个薪资区间 [最小值, 中点, 最大值]。

> 注意（2026-11-01 京东读书实读核对）：书里第4.3节对级宽/级差/重叠度**只做图示讲解，未给标准公式与数值样例**。下面 2–5 步的百分比与公式属**行业通用实践**，可作为落地参考；书内明确的原则只有两条——① 层级越高、级差越大；② 重叠度要"适度"（无重叠则无晋升空间、过度重叠则级别无意义）。

1. **定中点 (Midpoint)**：用 Step 2 的市场线（或内部线）在每个级别的取值作中点基准，再按 Step 3 战略上下浮动
2. **定级宽 (Range Width)**〔通用〕：基层 50–80%、中层 40–60%、高层 20–40%
3. **定级差 (Step Diff)**〔通用〕：相邻中点差 15–30%，越高层越大（书内原则：层级越高、级差越大）
4. **算最小值/最大值**：min = midpoint ÷ (1 + 级宽/2)，max = midpoint × (1 + 级宽/2)
5. **算重叠度**〔通用〕：相邻级别区间重叠 60–80%（基层）到 <20%（高层）；书内强调"适度重叠"最理想

- **完成标准**：一张《薪酬结构表》——每级 min/中点/max/级宽/级差/重叠度齐备，且级差随级别递增、级宽随级别递减。

### Step 5 — 薪酬架构搭建（四种方法，按数据条件选）

| 方法 | 适用 | 做法 |
|---|---|---|
| **仅用内部公平** | 没外部数据/强管控文化 | 用内部回归线定架构，所有点落在回归线附近 |
| **仅用外部竞争** | 新公司/无历史包袱 | 直接用市场线当架构，中点=市场P50(或战略分位) |
| **内外部结合** ★ | 大多数公司 | 内部线定形状、外部线定水平，取加权 |
| **点对点** | 关键岗位单独谈 | 对少数稀缺岗位单独对标，不进通用架构 |

- **完成标准**：所有人都能映射到架构的某个级别区间里，且 compa-ratio 落在 0.85–1.15 的合理带。

### Step 6 — 薪酬预算与调薪矩阵（把"该涨谁"算清楚）

> 本节已按京东读书正版实读第5.3节补实（2026-11-01），含书内真实矩阵表与计算原理。

**⓿ 调薪前先做数据诊断**（书里5.2）：按"部门/职位序列×级别×服务年限"算平均 CR（内部比率=实际工资÷中点值，理想≈100%），做成矩阵一眼看问题区——书里表5-13 就是"序列×级别"的 CR 表（如某序列某级 116%、另一序列某级仅 84%）。重点查**老员工"倚老卖老"倒挂**、哪些序列/级别系统性偏离。先诊断，再定预算和矩阵。

**① 预算由三块构成**（书里明确）：
- **绩效调薪预算（Merit Increase Budget）**：普调，按业绩分配，**不是平均分**
- **晋升预算（Promotion Budget）**：只给真晋升的人（随级别变动、涨幅通常较大）；**部门没员工晋升，这笔预算不能用**
- **特殊预算（Special / Catch-Up / Structural Budget）**：补历史遗留、对标市场差距、结构性调整

**② 调薪矩阵：横轴薪酬竞争力（CR），纵轴绩效**（书里核心；表5-19 为推荐实操版，每格给区间）

| 业绩 \ 薪酬竞争力 | CR<80%（偏低·绿圈） | 80%≤CR≤120%（合理） | CR>120%（偏高·红圈） |
|---|---|---|---|
| S（最优） | 13%–15% | 11%–13% | 9%–11% |
| 4 | 11%–13% | 9%–11% | 7%–9% |
| 3 | 7%–9% | 6.5%–7.5% | 3%–5% |
| 2 | 3%–5% | 1%–3% | 0% |
| 1（最差） | 0% | 0% | 0% |

**三条铁律（读矩阵）**：
1. 绩效越好涨越多；绩效最差（1）一律 0%
2. 同样绩效下，**CR 越低（低于区间=绿圈）涨越多、CR 越高（高于区间=红圈）涨越少**——低薪要补、高薪要控（书里表5-17 同构：绿圈 17% → 第三四区间 11% → 红圈 7%）
3. 每格给的是**区间**而非单一值，让业务经理有浮动空间（书里明确建议把单值矩阵改成区间，但测算要更周密，确保不超预算）

**③ 矩阵数值怎么算出来（书里 4 步工作原理）**：
1. 统计两组分布比例：员工在各薪酬区间的占比 a1…a4（和=100%）、在各绩效结果的占比 b1…b5（和=100%）
2. 每格建议值 × 该区间占比 a × 该绩效占比 b，全部加权求和 → 得**总体加权平均调薪率**
   例：`17%×a1×b1 + 14%×a2×b1 + … + 3%×a2×b4`
3. 让加权平均率 **≈ 或略小于预算**（书里案例预算 8%），超了就下调矩阵
4. **用真实员工薪酬数据验算**：按每人"绩效×CR"套矩阵算出新工资，汇总看总增幅是否超预算。⚠️ 书里特别提醒的坑：加权测算假设"工资平均分布"，但现实是**"高绩效员工往往工资也高"，会额外吃掉预算**，所以必须验算

**④ 特殊调整**：晋升调薪按新级别中点重置；应届生起薪贴近市场 P50。

- **完成标准**：一张"绩效×CR"的调薪矩阵（每格区间）+ 三块预算拆分表 + 真实数据验算的总增幅不超预算。

### Step 7 — 奖金与激励设计（书里按"薪酬哲学 / 人群 / 结构 / 业绩"展开，培训课归纳为 4P）

> 注：翁涛原书**并不使用"4P"这个标签**，而是从薪酬哲学、适用人群、薪酬结构、业绩指标四个角度展开；"4P/PMT"是外部培训对本书的归纳。下面按书里真实口径写。

- **薪酬哲学（Philosophy）**：公司愿为哪种行为付费？风险共担还是稳定保障？**随公司发展阶段变**：初创期控成本→"低基本工资 + 较高奖金比例"组合（若缺竞争力再提基薪），常用**股权激励**做长期绑定；成熟期可转为高基低奖。
- **适用人群（People）**：谁有资格拿奖金？销售 / 全员 / 高管？静态人群还是含动态变化？
- **薪酬结构（Position / 固浮比）**：奖金占年度总现金的**相对量**要分岗位、且在内部保持连贯（上下级奖金比例随管理级别提高而增大，因上级更贴近公司层面）。书里实例：**销售人员奖金占年度总现金 50%，行政后勤人员占 30%**。还要考虑销售 vs 非销售的**内部公平**。
- **业绩指标（Performance）**：付奖金锚定什么 KPI？销售锚收入/订单/回款，分层设门槛。

**销售激励建立流程**（书里四步）：项目计划 → 项目分析（现状/痛点）→ 构建实施（目标奖金/杠杆/门槛/封顶）→ 持续沟通。
**其他激励**：保留奖金（retention）、递延奖金（银行/金融常用，防短期冒险）。

- **完成标准**：一份奖金方案——目标奖金%、固浮比（含分岗位相对量）、KPI、门槛/封顶、支付节奏都写清，且说明发展阶段对应的哲学。

### Step 8 — 薪酬沟通

设计再好，沟通砸了也白搭。
- 给员工的：讲清"薪酬怎么定、为什么、我能怎么涨"（用 compa-ratio 和矩阵解释，别只给个数字）
- 给经理的：培训经理用调薪矩阵做分配对话
- 给高管的：用诊断表和架构表讲"钱花得值不值"

- **完成标准**：有《调薪大纲》+ 员工沟通话术 + 经理培训材料。

## B — 边界与常见失败模式（作者警告过的坑）

1. **用平均数代替分位分析** → 被高管薪资拉偏，掩盖倒挂。永远用分位/compa-ratio。
2. **职位评估变成"拍脑袋评级"** → 没有因素定义和打分表，级别失效。必须先建评估体系。
3. **盲目对标 P50** → 不结合自家薪酬战略，可能花冤枉钱或留不住人。先定战略再对标。
4. **调薪"大锅饭"** → 人人都涨一样多，等于没激励。必须用矩阵拉开差距。
5. **只看现金不顾总包** → 滞后型策略要用福利/发展补足，否则人留不住。
6. **架构搭完不维护** → 职位体系、市场线要定期(年)回检，否则迅速失真。
7. **作者盲点提醒**：本书偏外企/跨国公司视角，民企/初创的"老板一言堂"现实、股权激励税务、劳动法合规需另补专业意见。
