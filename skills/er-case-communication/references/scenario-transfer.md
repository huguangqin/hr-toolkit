# 场景D：调岗调薪

## 适用范围

因业务调整、组织架构变化、员工能力发展等原因，需要对员工进行岗位或薪资调整的场景。

## 法律依据

### 协商一致原则（《劳动合同法》第35条）
> 用人单位与劳动者协商一致，可以变更劳动合同约定的内容。变更劳动合同，应当采用书面形式。

### 法定可单方调岗情形
- 员工不能胜任工作（需有考核依据）
- 医疗期满后不能从事原工作
- 客观情况发生重大变化（如部门撤并）

## 操作流程

### Phase 1：评估调岗调薪必要性

**自检清单：**

```
□ 是否有明确的调岗调薪原因（业务调整/能力不匹配/组织优化）
□ 新岗位是否与员工能力匹配
□ 薪资调整是否合理（不低于当地最低工资、不低于原岗位太多）
□ 工作地点是否变化（变化需额外考虑）
□ 是否已尝试与员工协商
□ 是否存在法定保护期（孕期/医疗期/工伤等）
```

### Phase 2：方案设计

**调岗方案要素：**

| 要素 | 说明 | 注意事项 |
|------|------|---------|
| **新岗位名称** | 明确岗位名称和职责 | 与原岗位有关联性或合理性 |
| **新薪资结构** | 基本工资+绩效+补贴 | 降幅不宜过大（建议≤20%） |
| **工作地点** | 是否变化，通勤影响 | 跨城市需额外补偿或协商 |
| **汇报关系** | 新的上级和团队 | 提前与新团队沟通 |
| **生效日期** | 给员工适应时间 | 建议至少提前2周通知 |
| **试用期** | 是否设置新岗位试用期 | 同一单位只能约定一次试用期 |

**薪资调整参考标准：**
- 平调（同级别）：薪资不变或微调（±5%）
- 降级调岗：降幅建议≤20%，不低于同岗位最低档
- 晋升调岗：涨幅10-30%，与新岗位职责匹配

### Phase 3：沟通准备

使用 [communication-templates.md](communication-templates.md) 中"场景D"的话术模板。

**沟通前准备：**
1. 准备好调岗调薪的书面方案
2. 准备变更协议/确认书
3. 预判员工可能的疑虑和反对点
4. 准备应对方案（如适当让步）

### Phase 4：面谈执行

**沟通结构：**

1. **开场（2分钟）**
   - 说明沟通目的，营造开放氛围
   - "今天想和你聊聊接下来的工作安排"

2. **说明原因（5分钟）**
   - 客观陈述调整原因（业务/组织/个人发展）
   - 避免指责或负面评价

3. **介绍方案（5分钟）**
   - 逐项说明调整内容（岗位/薪资/地点/时间）
   - 强调新岗位的机会和发展空间

4. **倾听回应（10-15分钟）**
   - 让员工充分表达想法和顾虑
   - 认真倾听，不急于反驳
   - 记录员工的诉求

5. **协商调整（10分钟）**
   - 根据员工反馈适当调整方案
   - 在合理范围内灵活处理
   - 明确底线和可让步空间

6. **确认后续（5分钟）**
   - 给员工思考时间（3-5天）
   - 约定再次沟通时间
   - 说明如不同意的后续安排

### Phase 5：签署变更协议

**协议必备条款：**
- 原岗位/薪资 → 新岗位/薪资
- 生效日期
- 工作地点（是否变化）
- 其他变更内容（汇报关系、职责范围等）
- 双方签字确认

**注意事项：**
- 给员工充分阅读时间
- 允许员工咨询或带回审阅
- 一式两份，各执一份
- 保留签署记录

## 常见场景处理

### 场景1：组织调整导致的批量调岗

**处理要点：**
- 统一标准，避免歧视性安排
- 提前告知，给足适应时间
- 提供培训支持（如新岗位技能）
- 对不接受的员工，走协商解除流程

### 场景2：绩效不胜任的调岗

**处理要点：**
- 需先完成 PIP 流程（参见 scenario-pip.md）
- 新岗位应与员工能力匹配
- 薪资可相应调整，但不宜过低
- 需员工同意，不能强制

### 场景3：跨城市调岗

**处理要点：**
- 考虑通勤成本和生活影响
- 提供合理补偿（搬迁费、住房补贴等）
- 给予充分适应时间
- 如员工不同意，不能强制调动

### 场景4：员工拒绝调岗

**应对策略：**

| 员工态度 | 应对方式 |
|---------|---------|
| 有合理顾虑 | 调整方案（如增加补偿、延长过渡期） |
| 无理由拒绝 | 说明合理性，给予思考时间 |
| 坚决不同意 | 走协商解除流程（N+1） |

**注意：** 不能因员工拒绝调岗就直接解除，需走法定程序。

## 风险防控

### 高风险信号

- 🚩 调岗后薪资大幅下降（>30%）
- 🚩 工作地点跨城市变化，员工有家庭负担
- 🚩 员工处于保护期（孕期/医疗期/工伤）
- 🚩 调岗理由不充分或有歧视嫌疑
- 🚩 员工明确拒绝但公司强制执行

### 常见败诉原因

| 原因 | 说明 | 预防 |
|------|------|------|
| 未协商一致 | 单方强制调岗 | 充分沟通，取得同意 |
| 薪资降幅过大 | 影响基本生活 | 控制在合理范围（≤20%） |
| 岗位不合理 | 与原岗位差距过大 | 确保岗位关联性和合理性 |
| 未签书面协议 | 口头约定无效 | 必须签署变更协议 |
