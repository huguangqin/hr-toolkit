# 场景C：绩效不胜任 / PIP（绩效改进计划）

## 适用范围

员工绩效持续不达标，需要通过绩效改进计划（PIP）进行改善的场景。

## 法律依据

根据《劳动合同法》第40条第(二)项：
> 劳动者不能胜任工作，经过培训或者调整工作岗位，仍不能胜任工作的，用人单位提前三十日以书面形式通知劳动者本人或者额外支付劳动者一个月工资后，可以解除劳动合同。

**关键要求：必须先培训或调岗，不能直接解除。**

## 操作流程

### Phase 1：绩效不胜任认定

**前提条件（缺一不可）：**

```
□ 有明确的绩效考核标准和目标（事先告知员工）
□ 考核过程客观公正，有数据支撑
□ 考核结果已正式告知员工
□ 员工确实未达到岗位要求
□ 不胜任非因公司原因导致（如未提供必要资源）
```

**证据准备：**
- 绩效考核表（含评分依据）
- 工作目标/KPI 设定记录
- 实际完成情况的数据记录
- 员工签字确认的考核结果
- 历史绩效记录（证明非偶发）

### Phase 2：PIP 方案设计

**PIP 计划书必备要素：**

| 要素 | 要求 | 示例 |
|------|------|------|
| **改进期限** | 30/60/90天，视岗位复杂度 | 一般岗位60天，管理岗90天 |
| **改进目标** | 具体、可衡量、可达成（SMART） | "完成X个项目，客户满意度≥85%" |
| **评估节点** | 期中评估 + 期末评估 | 30天期中检查，60天终期评估 |
| **支持措施** | 培训、辅导、资源支持 | "安排资深同事一对一辅导" |
| **评估标准** | 明确通过/不通过的标准 | "完成全部目标且无重大投诉" |
| **未通过后果** | 明确告知可能的结果 | "调岗/协商解除/其他安排" |

**PIP 计划书模板结构：**

```
绩效改进计划书

员工姓名：___  岗位：___  部门：___
改进期间：____年__月__日 至 ____年__月__日（共__天）

一、当前绩效问题
[具体描述不胜任的表现，附数据]

二、改进目标
1. [具体目标1，含量化指标]
2. [具体目标2，含量化指标]
3. [具体目标3，含量化指标]

三、支持措施
1. 培训：[具体培训安排]
2. 辅导：[辅导人、频次]
3. 资源：[提供的工具/权限/支持]

四、评估安排
- 期中评估：[日期]，评估内容：[...]
- 期末评估：[日期]，评估内容：[...]

五、评估结果处理
- 通过：PIP结束，恢复正常管理
- 未通过：[调岗/协商解除/其他]

员工签字：________  日期：________
主管签字：________  日期：________
HR签字：  ________  日期：________
```

### Phase 3：PIP 启动沟通

使用 [communication-templates.md](communication-templates.md) 中"场景C1"的话术模板。

**沟通要点：**
- **定调**：PIP是帮助改进，不是处罚
- **客观**：用数据和事实说明绩效差距
- **倾听**：了解员工的困难和想法
- **支持**：强调公司提供的培训和辅导
- **明确**：清楚说明改进目标和评估标准

**常见员工反应及应对：**

| 员工反应 | 应对策略 |
|---------|---------|
| 否认绩效问题 | 用数据和事实回应，展示具体案例 |
| 归因于外部因素 | 承认客观困难，但聚焦个人可改进的部分 |
| 情绪激动 | 暂停，给时间冷静；表达理解和支持 |
| 拒绝签字 | 说明签字是确认知晓，不是认同；记录在案 |
| 要求调岗 | 如有合适岗位可考虑，否则继续PIP |

### Phase 4：PIP 执行期间管理

**期中评估（必须执行）：**
- 对照目标逐项评估进展
- 书面记录评估结果
- 与员工沟通反馈
- 必要时调整改进计划

**日常管理：**
- 定期（每周/每两周）一对一辅导
- 及时记录工作表现（好的和不好的）
- 保留所有沟通记录
- 有问题及时沟通，不等到评估时再说

### Phase 5：期末评估

**评估流程：**
1. 收集改进期间的绩效数据
2. 对照PIP目标逐项评估
3. 形成书面评估报告
4. 与员工面谈沟通结果

**结果处理：**

| 结果 | 处理方式 |
|------|---------|
| **通过** | PIP正式结束，书面通知，恢复正常管理 |
| **部分达成** | 视情况延长PIP或启动调岗/协商 |
| **未通过** | 进入下一步：调岗或协商解除 |

### Phase 6：PIP未通过后续处理

**优先选项：调岗**
- 如有合适岗位，优先安排调岗
- 新岗位应与员工能力匹配
- 需员工同意（不能强制调岗）

**备选选项：协商解除**
- 按协商解除流程处理（参见 [scenario-negotiation.md](scenario-negotiation.md)）
- 补偿标准：N+1（法定）或更高

**最后选项：单方解除**
- 需确保PIP流程完整合规
- 提前30天书面通知，或支付1个月代通知金
- 支付经济补偿金（N）
- 通知工会

## 风险防控

### 常见败诉原因

| 原因 | 说明 | 预防 |
|------|------|------|
| 绩效标准不明确 | 无书面标准或标准模糊 | 事先制定并告知员工 |
| 考核过程不公正 | 主观打分，无数据支撑 | 用客观数据和事实 |
| PIP流于形式 | 只走流程，无实质辅导 | 真正提供培训和支持 |
| 未给改进机会 | PIP期限太短或目标不合理 | 合理设定期限和目标 |
| 直接跳过PIP | 未经PIP直接解除 | 必须先PIP或调岗 |

### 高风险信号

- 🚩 员工在PIP期间提起仲裁/投诉
- 🚩 员工主张绩效标准未事先告知
- 🚩 PIP目标明显不合理（故意设高）
- 🚩 公司未提供承诺的培训/辅导
- 🚩 评估过程无记录或记录不完整
