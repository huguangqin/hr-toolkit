# 场景B：协商解除 / 劝退

## 适用范围

因组织调整、岗位撤消、人岗不匹配等原因，与员工协商解除劳动合同的场景。

## 核心原则

1. **自愿性**：协商解除必须基于双方自愿，不得胁迫
2. **合理性**：补偿方案合理，不低于法定标准
3. **完整性**：协议条款完整，避免后续争议

## 操作流程

### Phase 1：前期准备

1. **明确解除原因**
   - 组织调整/岗位撤消
   - 业务转型/缩编
   - 人岗不匹配（经评估）
   - 其他客观原因

2. **计算法定补偿标准**
   - 经济补偿金（N）：工作年限 × 月平均工资
   - 月工资上限：当地社平工资的3倍
   - 工作年限计算：每满1年计1个月，6个月以上不满1年按1年计，不满6个月按0.5个月计
   - 代通知金：如未提前30天通知，需额外支付1个月工资

3. **设计协商方案**
   - 基础方案：N（法定最低）
   - 优化方案：N+1 或更高（视情况）
   - 附加条件：延长社保缴纳、提供推荐信、延长找工作时间等

### Phase 2：初次沟通

使用 [communication-templates.md](communication-templates.md) 中"场景B1"的话术模板。

**沟通要点：**
- 营造轻松氛围，不预设结论
- 先倾听员工想法，了解其诉求
- 说明背景原因（业务调整等客观因素）
- 提出协商方向，观察员工反应
- **不要第一次就抛出具体方案**，先探底

**关键禁忌：**
- ❌ 不能说"你必须离职"
- ❌ 不能威胁"不签就单方解除"
- ❌ 不能限制员工寻求法律咨询
- ❌ 不能承诺超出权限的条件

### Phase 3：方案协商

1. **给出思考时间**：至少3-5个工作日
2. **正式提出方案**：书面列出所有条款
3. **允许修改**：在合理范围内可协商调整
4. **确认意愿**：员工明确表示同意（非被迫）

### Phase 4：签署协议

**协议必备条款：**
- 双方协商一致解除
- 解除日期
- 经济补偿金额及支付方式
- 工资结算日期
- 社保/公积金缴纳截止月份
- 工作交接安排
- 双方权利义务终止条款
- 争议解决方式

**签署注意事项：**
- 给员工充分时间阅读（可带走）
- 建议员工咨询专业人士
- 双方签字 + 日期 + 公司盖章
- 一式两份，各执一份

### Phase 5：离职交接

| 事项 | 责任人 | 时间节点 |
|------|--------|---------|
| 工作交接 | 直属上级 | 解除日前完成 |
| 资产归还 | IT/行政 | 最后工作日 |
| 系统权限关闭 | IT | 解除日当天 |
| 工资结算 | 财务/HR | 约定日期 |
| 补偿金支付 | 财务 | 约定日期（通常随最后一次工资） |
| 离职证明 | HR | 解除当日出具 |
| 社保/公积金转移 | HR | 解除后1个月内 |

## 风险防控

### 高风险信号

| 信号 | 风险 | 应对 |
|------|------|------|
| 员工明确拒绝协商 | 强行解除=违法 | 暂停，评估其他路径 |
| 员工录音/录像 | 后续可能作为证据 | 确保全程合规，自己也录音（提前告知） |
| 员工提出不合理高额补偿 | 谈判僵局 | 坚守底线，说明法定标准 |
| 员工处于保护期（孕期/医疗期等） | 法律禁止协商解除 | 停止，等保护期结束 |

### 常见陷阱

1. **"假协商真逼退"**：表面协商，实际施压 → 协议可能被认定无效
2. **口头承诺不兑现**：所有承诺必须写入协议
3. **补偿低于法定标准**：即使员工同意，也可能被仲裁推翻
4. **协议条款模糊**：使用"一次性了结"等模糊表述，未明确具体金额

## 特殊情况处理

### 员工要求"被辞退"而非"协商解除"

- 理解员工诉求（可能是为了领失业金）
- 解释两种方式的法律后果差异
- 协商解除：双方自愿，补偿明确
- 被辞退：需有合法理由，否则构成违法解除（2N）
- **建议**：坚持协商解除，可在补偿上适当让步

### 员工情绪激动

- 暂停沟通，给员工冷静时间
- 表达理解和尊重
- 不激化矛盾，不争论对错
- 必要时安排心理咨询支持
