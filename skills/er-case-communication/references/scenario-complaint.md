# 场景E：员工投诉 / 申诉处理

## 适用范围

员工对公司管理、工作环境、同事行为等提出投诉或申诉的场景。

## 核心原则

1. **中立客观** — 不预设立场，不偏向任何一方
2. **及时响应** — 收到投诉后24小时内启动调查
3. **隐私保护** — 严格控制信息范围，保护投诉人
4. **闭环反馈** — 调查有结果后及时反馈

## 投诉类型分类

| 类型 | 典型场景 | 紧急程度 | 处理时限 |
|------|---------|---------|---------|
| **职场骚扰** | 性骚扰、言语骚扰、恐吓 | 🔴 紧急 | 24小时内启动 |
| **职场歧视** | 性别/年龄/地域/宗教歧视 | 🔴 紧急 | 24小时内启动 |
| **管理不公** | 分配不均、考核不公、晋升不透明 | 🟡 重要 | 3个工作日 |
| **薪酬争议** | 工资计算错误、加班费、提成 | 🟡 重要 | 3个工作日 |
| **工作环境** | 设施安全、卫生条件、噪音 | 🟢 一般 | 5个工作日 |
| **同事纠纷** | 工作冲突、人际矛盾 | 🟢 一般 | 5个工作日 |

## 操作流程

### Phase 1：接收投诉（当天）

**接收方式：**
- 口头投诉（面谈/电话）
- 书面投诉（邮件/即时消息）
- 匿名投诉（举报箱/热线）

**接收记录模板：**

```
投诉登记表

投诉人：___ （匿名则填"匿名"）
投诉时间：____年__月__日 __:__
投诉方式：□口头 □书面 □匿名 □其他

被投诉人：___ （如不明确填"待确认"）
被投诉人部门：___

投诉内容摘要：
[简要描述投诉事项]

初步分类：
□职场骚扰 □职场歧视 □管理不公 □薪酬争议 □工作环境 □同事纠纷 □其他

接收人签字：________  日期：________
```

**首次回应话术：**

```
"[姓名]，你反馈的情况我已经记录了。
感谢你的信任，公司会认真对待每一个投诉。
接下来，我们会在 [时限] 内启动调查，
可能会约谈相关人员进行了解。
调查结束后，我会第一时间给你反馈结果。
期间如果有任何问题，随时可以找我。"
```

### Phase 2：初步评估（1个工作日内）

**评估内容：**

```
□ 投诉事项是否属于公司管辖范围
□ 是否涉及紧急/高风险情形（骚扰、歧视、安全隐患）
□ 是否需要立即采取临时措施（如隔离当事人）
□ 是否需要法务/合规部门介入
□ 是否需要外部机构介入（如劳动监察、公安）
```

**临时措施（必要时）：**
- 暂时调整工作安排，避免当事人接触
- 暂停被投诉人的某些权限
- 安排心理支持（如EAP服务）

### Phase 3：正式调查（按投诉类型时限）

**调查组构成：**
- 至少2人组成调查组
- 至少1人为HR专业人员
- 如涉及直属上级，上级不参与调查
- 必要时引入法务或外部调查员

**调查步骤：**

1. **约谈投诉人**（详细取证）

```
开场：
"感谢你来。今天想详细了解你反映的情况，
请你尽量详细地描述，包括时间、地点、
涉及人员、具体经过。"

关键问题：
- 具体发生了什么事？
- 什么时间、在哪里发生的？
- 当时有谁在场？
- 这件事发生过几次？
- 你当时有什么反应？
- 有什么证据吗（聊天记录/邮件/录音）？
- 你希望公司怎么处理？

记录要求：
- 逐字记录关键陈述
- 记录时间线和关键事实
- 让投诉人确认记录准确性
- 投诉人签字确认
```

2. **约谈被投诉人**（听取陈述）

```
开场：
"今天找你了解一些情况，是常规的调查流程。
请你如实说明情况。"

告知被投诉事项：
"有同事反映 [简述投诉内容]，
想听听你的说法。"

关键问题：
- 对于这件事，你的说法是什么？
- 有没有什么需要补充或澄清的？
- 有没有相关的证据或证人？

注意事项：
- 保持中立，不做有罪推定
- 给予充分申辩机会
- 不透露投诉人身份（如可能）
```

3. **约谈证人**（如适用）

```
开场：
"今天想了解一些情况，请你如实描述你看到/听到的。
你的信息会严格保密。"

关键问题：
- 你了解 [事件] 的情况吗？
- 你看到了什么、听到了什么？
- 当时的具体情况是怎样的？

注意事项：
- 分别约谈，避免串供
- 不透露其他证人的说法
- 做好书面记录并签字
```

4. **收集证据**

```
证据类型：
- 聊天记录（完整截图或导出）
- 电子邮件（含邮件头）
- 监控视频（原始文件）
- 考勤记录（系统导出）
- 业务系统日志
- 书面材料（签字件）
```

### Phase 4：调查结论

**形成调查报告：**

```
调查报告

一、投诉事项
[简述投诉内容]

二、调查过程
- 调查时间：[日期范围]
- 调查组成员：[姓名]
- 约谈人员：[名单]
- 收集证据：[清单]

三、事实认定
[基于证据认定的事实，区分"已证实""无法证实""不属实"]

四、处理建议
[基于事实和制度，提出处理建议]

五、改进措施（如适用）
[针对系统性问题的改进建议]

调查组签字：________  日期：________
```

**结论类型：**

| 结论 | 说明 | 后续动作 |
|------|------|---------|
| 投诉属实 | 证据充分，违纪事实成立 | 启动纪律处分流程 |
| 部分属实 | 部分事实成立，部分无法证实 | 对成立部分处理 |
| 不属实 | 证据不足或事实不成立 | 向投诉人说明，结案 |
| 误解/沟通问题 | 非违纪，但存在沟通问题 | 调解沟通，改进流程 |

### Phase 5：反馈投诉人

使用 [communication-templates.md](communication-templates.md) 中"场景E"的话术模板。

**反馈要点：**
- 告知调查结论（属实/不属实/部分属实）
- 说明处理决定（如已处分被投诉人）
- 说明改进措施（如有）
- 询问是否满意，是否需要进一步帮助
- 如不满意，告知进一步申诉渠道

**反馈话术：**

```
"[姓名]，关于你之前反映的问题，调查已经完成。
调查结论是：[属实/部分属实/不属实]。
公司的处理决定是：[具体处理措施]。
同时，我们也会 [改进措施]。
你对这个结果有什么疑问吗？
如果还有其他问题，随时可以找我。"
```

### Phase 6：结案归档

**归档材料：**
- 投诉登记表
- 调查报告
- 约谈记录（投诉人、被投诉人、证人）
- 证据材料
- 处理决定文件
- 反馈记录
- 改进措施跟进记录

**保密要求：**
- 投诉材料单独存档，不放入员工档案
- 限制查阅权限（仅HR负责人和相关管理层）
- 投诉人信息严格保密

## 特殊情况处理

### 匿名投诉

- 同样需要调查，但无法约谈投诉人
- 通过其他证据和证人了解情况
- 在适当范围内公开调查结果

### 重复投诉

- 核查是否为新问题还是对原处理不满
- 如对原处理不满，可启动复查程序
- 如有新证据，补充调查

### 恶意投诉

- 查实后对投诉人进行教育
- 情节严重的，按违纪处理
- 注意：需有充分证据证明是恶意诬告，不能仅因"查无实据"就认定为恶意

### 群体性投诉

- 成立专项调查组
- 分别约谈投诉人，了解共性问题
- 可能存在系统性管理问题，需组织层面改进

## 风险防控

### 高风险信号

- 🚩 投诉涉及性骚扰或歧视
- 🚩 投诉人是高管或被投诉人是高管
- 🚩 涉及多名员工（群体性事件）
- 🚩 投诉人已联系律师或媒体
- 🚩 投诉内容涉及违法违规（如商业贿赂、安全事故隐瞒）

### 常见错误

| 错误 | 后果 | 预防 |
|------|------|------|
| 不及时处理 | 问题升级、员工不信任 | 24小时内启动调查 |
| 偏袒一方 | 投诉人不满、可能仲裁 | 保持中立、证据说话 |
| 泄露投诉人信息 | 报复投诉人、信任崩塌 | 严格保密 |
| 不做记录 | 无法追溯、无法复盘 | 全程书面记录 |
| 不反馈结果 | 投诉人感觉被忽视 | 及时闭环反馈 |

## 时间线管理

| 节点 | 时限 | 责任人 |
|------|------|--------|
| 接收投诉 | 当天 | 接收人 |
| 初步评估 | 1个工作日 | HR |
| 启动调查 | 紧急24h / 一般3天 | 调查组 |
| 完成调查 | 紧急3天 / 一般7天 | 调查组 |
| 形成报告 | 调查完成后2天 | 调查组 |
| 反馈投诉人 | 报告完成后1天 | HR |
| 执行处理 | 反馈后3天内 | 相关部门 |
