# 沟通话术模板

> 本文件提供各场景下的沟通话术框架。使用时需根据具体情况调整措辞，切忌照本宣科。

---

## 通用沟通原则

### 开场基调
- 选择私密、不受打扰的空间
- 建议至少2人在场（HR + 业务主管）
- 开场说明沟通目的，不设预设结论

### 全程要求
- 语速平稳，不使用威胁性、侮辱性语言
- 允许员工充分表达，不频繁打断
- 关注员工情绪变化，必要时暂停休息
- 面谈记录双方签字确认

## 场景 A：违纪处理沟通

### A1. 调查阶段 — 事实确认谈话

```
开场：
"[姓名]，今天找你聊聊，主要是想就 [具体时间/事件] 的一些情况
做个了解。这是正常的沟通流程，请你如实说明情况就好。"

事实核实：
"根据我们了解到的情况，[陈述客观事实，不带评价]。
对于这件事，你有什么要补充或说明的吗？"

证据确认（如有书面/电子证据）：
"这是 [证据名称]，你看一下，这是你本人的 [操作/发言/记录] 吗？"

记录确认：
"我把今天谈话的要点记录下来了，我们一起确认一下内容是否准确。
确认没问题的话，请你签个字。"
```

### A2. 处罚告知 — 处分决定通知

```
开场：
"[姓名]，上次沟通后，公司对你的情况进行了核实和评估。
今天正式和你沟通处理结果。"

说明决定：
"经过调查核实，你在 [时间] 存在 [具体违纪行为] 的行为。
根据公司《[制度名称]》第 [X] 条的规定，该行为属于 [违纪等级]。
综合考虑 [列举考量因素]，公司决定给予你 [具体处分] 的处理。"

告知权利：
"如果你对处理结果有异议，可以在 [X] 个工作日内向 [部门] 提出申诉。
这是你的正当权利，公司会认真对待。"

签署文书：
"这是 [处分通知书/警告函]，请你确认签收。"
```

### A3. 解除通知 — 违纪解除

```
开场：
"[姓名]，感谢你抽时间来。今天的沟通比较重要，[另一位在场人姓名] 
也在场作为见证。"

陈述事实与依据：
"经公司调查核实，你在职期间存在以下行为：
[逐一列举违纪事实]。
上述行为违反了公司《[制度名称]》第 [X] 条的规定，属于 [严重违纪/红线行为]。"

说明程序合规性：
"公司在做出这个决定前，已经完成了以下程序：
- 就相关事实与你进行了沟通确认
- 征询了工会意见
- 依据公司依法制定的规章制度作出了处理"

告知决定：
"鉴于上述情况，公司决定与你解除劳动合同，最后工作日为 [日期]。
关于经济补偿 [如有]、社保转移、工作交接等事项，接下来会逐项与你说明。"

后续安排：
"关于离职手续：
1. 最后工作日 [日期]，请完成工作交接
2. 工资结算至 [日期]，将于 [时间] 发放
3. [如有补偿] 经济补偿金 [金额]，将随最后一次工资一并支付
4. 社保/公积金缴纳至 [月份]，之后你可以自行办理转移"
```

## 场景 B：协商解除 / 劝退

### B1. 初次沟通

```
开场：
"[姓名]，今天想和你聊一聊工作上的事，比较放松地交流一下。"

引入话题：
"最近一段时间，[业务调整/组织变化/绩效情况]，公司也在思考
如何更好地安排各岗位的工作。想先听听你自己的想法和感受。"

倾听：
（给员工充分时间表达，认真倾听，不做评价性回应）

提出方向：
"基于目前的情况，公司觉得可能有一个方案我们可以一起探讨一下。
如果双方能够协商一致，我们会提供一个对你比较有利的方案。
当然，这只是探讨，不会强迫你做决定。"

提出方案（如员工愿意听）：
"公司的初步方案是：
- 协商解除劳动合同
- 公司支付 [N/N+1/具体金额] 的经济补偿
- 最后工作日为 [日期]，在此之前你可以 [找工作/交接]
- [其他条件，如推荐信、延长社保等]
你可以考虑一下，不急，[X天] 内给我答复都可以。"
```

### B2. 协商达成一致

```
确认意愿：
"[姓名]，你考虑好了吗？你确认同意协商解除的方案吗？"

确认条款：
"我再和你确认一下具体条款：
1. 双方协商解除劳动合同，解除日期为 [日期]
2. 公司支付经济补偿金 [金额]
3. 工资结算至 [日期]
4. [其他条款]
这些内容都会写进协商解除协议中。"

签署协议：
"这是协商解除协议书，请你仔细阅读每一项条款。
如有不清楚的地方可以问我，也可以带回去请专业人士看一下。
确认没问题后签字。"
```

## 场景 C：绩效不胜任 / PIP

### C1. 绩效反馈 + PIP 启动

```
开场：
"[姓名]，今天我们聊聊你的绩效情况。这是一个正式的沟通，
目的是帮助你了解现状，并一起找到改进方向。"

反馈绩效：
"在过去的 [考核周期] 中，你的绩效结果是 [结果]。
具体来说：
- [维度1]：[表现描述 + 具体事例]
- [维度2]：[表现描述 + 具体事例]
与岗位要求的差距主要在 [具体差距]。"

倾听员工反馈：
"对于这个结果，你有什么想说的？或者有什么客观困难需要我知道的？"

介绍 PIP：
"根据公司制度，绩效不胜任的情况下，我们会启动一个绩效改进计划（PIP）。
这不是处罚，而是给你一段集中改进的时间和支持。
PIP 的内容包括：
- 改进期限：[30/60/90天]
- 改进目标：[具体、可衡量的目标]
- 支持措施：[培训、辅导、资源支持]
- 评估方式：[期中评估 + 期末评估]"

确认签字：
"这是 PIP 计划书，我们一起过一遍。
你确认理解并签署后，改进期就正式开始了。"
```

### C2. PIP 期满评估

```
如改进通过：
"恭喜，经过 [X天] 的改进期，你的表现达到了预期目标。
PIP 正式结束，接下来继续保持就好。"

如改进未通过：
"[姓名]，PIP 改进期结束了。我们对照之前设定的目标来看一下结果：
- 目标1：[达成/未达成，说明]
- 目标2：[达成/未达成，说明]
很遗憾，整体未达到预期。根据制度，接下来公司会考虑：
[调岗 / 协商解除 / 其他方案]。
我们可以一起探讨哪个方案对你最合适。"
```

## 场景 D：调岗调薪沟通

```
开场：
"[姓名]，今天找你聊聊，是关于你接下来的工作安排。"

说明原因：
"由于 [业务调整/组织架构变化/个人发展需要]，公司希望对你的岗位
做一些调整。先听听你的想法。"

介绍调整方案：
"具体方案是：
- 现岗位：[岗位名称] → 新岗位：[岗位名称]
- 现薪资：[金额] → 新薪资：[金额]
- 工作地点：[是否变化]
- 汇报关系：[变化说明]
- 生效日期：[日期]"

倾听与协商：
"你对这个调整有什么想法或顾虑？"
（根据员工反馈调整或解释）

确认：
"如果你同意这个方案，我们签署一份岗位变更确认书。
如果暂时有顾虑，可以给你 [X天] 时间考虑。"
```

## 场景 E：员工投诉/申诉处理

```
接收投诉：
"[姓名]，你反馈的情况我已经了解了。感谢你的信任，
公司会认真对待每一个投诉/申诉。"

了解诉求：
"你希望公司怎么处理这件事？你的期望结果是什么？"

告知流程：
"接下来，我们会：
1. 在 [X个工作日] 内启动调查
2. 可能会约谈相关人员进行了解
3. 调查结束后 [X个工作日] 内给你反馈结果
4. 如果你对结果不满意，可以向上级/合规部门进一步申诉"

跟进反馈：
"[姓名]，关于你之前反映的问题，调查已经完成。
调查结论是：[结论]。
公司的处理决定是：[决定]。
你对这个结果有什么疑问吗？"
```

## 场景 F：高风险情形特别提示

### 员工情绪激动时
```
"我理解这对你来说很不容易，你的心情我能理解。
我们不着急，你可以先缓一缓，等你准备好了我们再继续聊。"
```

### 员工提出法律威胁时
```
"你当然有权利通过法律途径维护自己的权益，这是你的合法权利。
我们今天沟通的目的，是希望能找到一个双方都能接受的解决方案。
无论如何，公司都会依法处理。"
```

### 员工拒绝签字时
```
"签字不代表你同意，只是确认你今天收到了这份文件、了解了内容。
如果你不愿意签字也没关系，我们可以在场见证人签字，
证明文件已经向你送达。"
```

### 员工要求录音时
```
"如果你希望录音作为自己的记录，可以。
那我们也同步录音，确保双方都有完整的记录。"
```
