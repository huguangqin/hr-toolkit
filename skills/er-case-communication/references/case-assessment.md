# 案件评估框架

## 一、案件分级

### 按严重程度分类

| 级别 | 情形 | 建议处理方式 |
|------|------|------------|
| **L1-轻微** | 初犯、过失性、未造成损失（如偶尔迟到、轻微操作失误） | 口头警告 → 书面记录 |
| **L2-一般** | 重复轻微违纪、或单次造成一定影响（如未按流程操作致客户投诉） | 书面警告 → 绩效记录 |
| **L3-较重** | 多次违纪不改、或造成明显损失（如虚假报销小额、严重失职） | 记过/降级 → PIP 或协商调整 |
| **L4-严重** | 严重违反规章制度（如职务侵占、商业贿赂、严重泄密） | 红线解除（须证据充分） |

### 按案件类型分类

| 类型 | 常见场景 | 关键风险点 |
|------|---------|-----------|
| **违纪解除** | 虚假考勤、私飞单、收受贿赂、违反红线 | 证据链完整性、处罚比例、工会通知 |
| **协商解除** | 组织调整、岗位撤消、人岗不匹配 | 协商自愿性、补偿合理性、协议条款 |
| **绩效不胜任** | 连续低绩效、PIP未通过 | 绩效标准客观性、PIP 过程记录 |
| **调岗调薪** | 架构调整、业务转型 | 协商一致性、薪资合理性 |
| **员工投诉** | 职场霸凌、性骚扰、不公平对待 | 调查中立性、隐私保护、及时响应 |

## 二、处罚适配评估矩阵

在做出任何处分决定前，逐项评估以下维度：

```
┌──────────────────────────────────────────────────┐
│               处罚适配评估表                       │
├─────────────┬────────┬────────┬────────┬─────────┤
│ 评估维度     │ 轻     │ 中     │ 重     │ 权重    │
├─────────────┼────────┼────────┼────────┼─────────┤
│ 1.主观意图   │ 过失   │ 明知   │ 故意   │ ★★★★★  │
│ 2.行为次数   │ 初犯   │ 2-3次  │ 多次   │ ★★★★   │
│ 3.涉及金额   │ <1千   │ 1千-1万│ >1万   │ ★★★★   │
│ 4.实际损失   │ 无     │ 可控   │ 重大   │ ★★★★★  │
│ 5.影响范围   │ 个人   │ 团队   │ 公司   │ ★★★    │
│ 6.认错态度   │ 主动承认│ 被动承认│ 否认   │ ★★★    │
│ 7.历史记录   │ 无     │ 有过警告│ 累犯   │ ★★★    │
│ 8.制度明确度 │ 模糊   │ 有规定 │ 明确红线│ ★★     │
└─────────────┴────────┴────────┴────────┴─────────┘

判定原则：
- 全部"轻"列 → 口头/书面警告，不建议解除
- 多数"中"列 → 记过/降级/PIP，谨慎解除
- 多项"重"列 → 可考虑解除，但须确保程序完备
- 关键红线：只要"主观意图=过失"且"实际损失=无"，
  一律不建议直接解除
```

## 三、证据完整性检查清单

### 违纪案件证据包

每起违纪案件必须准备以下证据包，按编号逐项核查：

| 序号 | 证据项 | 要求 | 核查 |
|------|--------|------|------|
| 1 | 规章制度文本 | 现行有效版本，经民主程序证明 | □ |
| 2 | 制度公示/签收记录 | 该员工签字确认版本 | □ |
| 3 | 违纪事实证据 | 原始载体（非截图/复印件） | □ |
| 4 | 证人证言（如有） | 书面+身份证复印件 | □ |
| 5 | 员工本人陈述/申辩记录 | 面谈记录签字件 | □ |
| 6 | 工会通知记录 | 解除前通知，有工会签收 | □ |
| 7 | 解除通知书 | 送达签收/快递签收 | □ |
| 8 | 面谈记录 | 双方签字 | □ |

### 电子证据特别要求

- **监控视频**：保留原始文件（含系统时间戳），不可仅提供截图或翻拍
- **考勤数据**：从系统直接导出原始记录，附系统日志
- **聊天记录**：完整上下文截图，关键消息做公证保全
- **电子邮件**：保留原始邮件（含邮件头信息）
- **系统操作日志**：从后台导出，加盖时间戳

## 四、风险等级预判

在启动任何处理流程前，进行风险预判：

| 风险等级 | 特征 | 应对策略 |
|---------|------|---------|
| **低风险** | 事实清楚、证据充分、员工配合、无特殊情况 | 按标准流程执行 |
| **中风险** | 事实基本清楚但员工有争议、或存在轻微程序瑕疵 | 加强证据收集、法务预审 |
| **高风险** | 事实有争议、证据不充分、员工在保护期内、或涉及群体性事件 | 暂缓处理、专项讨论、法务全程参与 |

### 高风险红旗信号

遇到以下任一情况，**暂停流程，升级到法务/合规团队**：

- 🚩 员工处于医疗期、孕期、产期、哺乳期
- 🚩 员工近期有工伤认定或职业病诊断
- 🚩 涉及3人以上的群体性处理
- 🚩 员工已有律师或明确表示将仲裁/诉讼
- 🚩 违纪事实的关键证据缺失或有争议
- 🚩 涉及外籍员工、劳务派遣等特殊用工形式
- 🚩 员工曾向公司举报过违法违规事项（报复嫌疑）

## 五、贝壳整装业务场景补充

### 常见违纪类型及处理建议

| 违纪类型 | 高发岗位 | 处罚适配建议 |
|---------|---------|------------|
| 虚假考勤 | 外勤设计师、经营部经理 | 需结合GPS+打卡+实地核查，首次书面警告 |
| 私飞单 | 商务顾问、设计师 | 金额是关键——小额(<5000)不宜直接红线 |
| 推荐外购产品 | 设计师、项目经理 | 需证明主观恶意和实际损失 |
| 收受供应商利益 | 采购、项目经理 | 200元以下建议警告，大额可红线 |
| 虚假验收 | 项目经理、工程部 | 需区分主观造假 vs 标准理解差异 |
| 利益关系未申报 | 各级管理者 | 区分"未申报"和"隐瞒牟利" |

### 整装业务特殊考量

1. **外勤性质**：设计师和项目经理经常外出，考勤管理需考虑实际工作模式
2. **项目制运作**：项目周期长，中途换人成本高，解除决策需考虑项目影响
3. **供应商关系**：涉及大量供应商往来，利益关系的界定需具体分析
4. **客户满意度**：涉及客户投诉的违纪，需同时关注客户侧影响和处理
