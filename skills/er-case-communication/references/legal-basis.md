# 法律依据与风险防控

## 一、核心法律条款速查

### 1. 用人单位单方解除（《劳动合同法》第39条 — 无需补偿）

员工有下列情形之一，用人单位可解除劳动合同且无需支付经济补偿：

| 条款 | 情形 | 实操要点 |
|------|------|---------|
| (一) | 试用期不符合录用条件 | 需有明确录用条件且已告知，试用期内作出 |
| (二) | 严重违反规章制度 | **最常用**，须证明：制度合法+已公示+行为严重 |
| (三) | 严重失职、营私舞弊，给用人单位造成重大损害 | 需证明"严重"和"重大损害"的因果关系 |
| (四) | 同时与其他用人单位建立劳动关系，严重影响本单位工作 | 需有兼职事实证据 |
| (五) | 以欺诈手段使劳动合同无效 | 如学历造假、伪造工作经历 |
| (六) | 被依法追究刑事责任 | 注意：行政拘留不等于刑事处罚 |

### 2. 需支付经济补偿的解除（第40条）

| 条款 | 情形 | 补偿标准 |
|------|------|---------|
| (一) | 医疗期满不能从事原工作，也不能从事另行安排的工作 | N + 1（或提前30天通知） |
| (二) | 不能胜任工作，经培训或调岗后仍不能胜任 | N + 1（或提前30天通知） |
| (三) | 客观情况发生重大变化，协商不成 | N + 1（或提前30天通知） |

### 3. 法定不得解除情形（第42条）

- 从事接触职业病危害作业未进行离岗前职业健康检查
- 疑似职业病诊断/医学观察期间
- 职业病/工伤丧失或部分丧失劳动能力
- **医疗期内**（病假期间）
- **孕期、产期、哺乳期**
- 连续工作满15年且距退休不足5年

### 4. 工会通知义务（第43条）

用人单位单方解除劳动合同，**应当事先将理由通知工会**。未通知工会的解除，程序上违法。

## 二、败诉高频原因与防控

### 原因一：处罚过重（占比33%）

**法律规定：** 即使员工有违纪行为，仲裁委/法院会审查处罚的"比例性"。"严重违反"需达到严重程度，轻微违纪直接解除易被认定违法。

**防控措施：**
- 建立处罚梯度：口头警告 → 书面警告 → 记过 → 降级 → 解除
- 解除前做"处罚适配评估"：

```
评估维度：
1. 违纪行为性质（主观恶意 vs 过失）
2. 违纪金额/影响范围
3. 是否造成实际损失
4. 是否初犯/累犯
5. 是否有从轻情节（主动承认、积极配合等）
6. 类似案例的历史处理一致性
```

### 原因二：证据链断裂（占比25%）

**法律规定：** 用人单位对解除理由承担举证责任。证据不足 = 违法解除。

**证据保全 SOP：**

| 证据类型 | 保全要求 | 常见错误 |
|---------|---------|---------|
| 监控视频 | 保留原始文件（含时间戳），不可仅截图 | 仅提供截图/二次翻拍，被判无效 |
| 打卡记录 | 从考勤系统导出原始数据，加盖公司章 | 仅有Excel汇总表，员工否认 |
| 聊天记录 | 公证或截图含完整对话上下文 | 断章取义的截图 |
| 书面材料 | 员工签字确认原件 | 无签名的打印件 |
| 电子邮件 | 保留原始邮件（含邮件头） | 仅打印正文 |
| 证人证言 | 证人出庭或书面证言+身份证复印件 | 仅有口头陈述 |

### 原因三：程序瑕疵（占比17%）

**必走程序清单：**

```
□ 制度民主程序 — 职工代表大会或全体职工讨论通过
□ 制度公示/签收 — 员工签字确认已阅读并理解
□ 工会通知 — 违纪解除前必须通知工会并记录
□ 解除通知书送达 — 当面送达并签收，或邮寄送达并保留快递单
□ 面谈记录 — 双方签字的面谈笔录
□ 经济补偿计算 — 准确计算并在解除时一并支付
```

### 原因四：管理漏洞（占比25%）

**典型问题：**
- 用"考勤违纪"名义处理"组织调整"——实质是岗位调整协商不成
- 长期不处理某行为（如住所打卡），突然以此为由解除——被视为默示同意
- 管理层存在与制度矛盾的口头指令（如"允许收返佣"）

**防控原则：**
- 违纪就是违纪处理，不得将非违纪问题包装成违纪解除
- 发现异常行为应在30天内处理并记录，不得"秋后算账"
- 管理层口头指令如与制度矛盾，以制度为准，且应及时书面纠正

## 三、经济补偿金计算

### 基本公式

```
经济补偿金（N）= 工作年限 × 月平均工资
违法解除赔偿金（2N）= N × 2
代通知金 = 1个月工资（第40条未提前30天通知时）
```

### 工作年限计算

| 情况 | 计算 |
|------|------|
| 满1年 | 1个月 |
| 6个月以上不满1年 | 1个月 |
| 不满6个月 | 0.5个月 |

### 月平均工资

- 解除前12个月的平均工资
- 包含：基本工资 + 绩效奖金 + 津贴补贴 + 加班费等全部应发工资
- **上限**：月平均工资超过当地上年度职工月平均工资3倍的，按3倍计算，且补偿年限最高不超过12年

## 四、仲裁应对要点

### 时效
- 劳动争议发生之日起 **1年内** 申请仲裁
- "争议发生之日"通常指员工知道或应当知道权利被侵害之日

### 举证责任
- **用人单位举证**：对解除/终止理由承担举证责任
- 关键证据清单：规章制度文本、员工签收记录、违纪事实证据、工会通知记录、解除通知书

### 仲裁流程
1. 员工提交仲裁申请
2. 仲裁委5日内决定是否受理
3. 受理后45日内结案（复杂可延长15日）
4. 不服可在15日内向法院起诉
