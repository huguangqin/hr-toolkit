# 场景A：违纪解除（红黄线）

## 适用范围

员工违反公司规章制度（红黄线），需要进行纪律处分直至解除劳动合同的场景。

## 整装业务常见违纪类型

| 类型 | 高发岗位 | 严重程度 | 常见败诉风险 |
|------|---------|---------|------------|
| 虚假考勤 | 外勤设计师、经营部经理 | 中-高 | 长期未管理=默示同意；证据未保全原始载体 |
| 私飞单 | 商务顾问、设计师 | 高 | 需证明主观恶意和实际损失 |
| 推荐外购产品 | 设计师、项目经理 | 中 | 金额小（<5000元）时直接红线易被判过重 |
| 收受供应商利益 | 采购、项目经理 | 视金额 | 200元以下建议警告，大额可红线 |
| 虚假验收 | 项目经理、工程部 | 高 | 需区分主观造假 vs 标准理解差异 |
| 利益关系未申报 | 各级管理者 | 中 | 区分"未申报"和"隐瞒牟利" |
| 职务侵占 | 全岗位 | 高 | 证据链必须完整，工会程序必须合规 |

## 操作流程

### Phase 1：事实调查（1-3个工作日）

1. **收集原始证据**
   - 考勤数据：从系统导出原始记录（非Excel汇总）
   - 监控视频：保留原始文件含时间戳（不可仅截图）
   - 聊天记录：完整上下文截图，关键消息做公证
   - 业务记录：系统操作日志、客户投诉原件

2. **当事人陈述**
   - 安排正式面谈，告知员工被调查的事项
   - 给予充分申辩机会，做好书面记录
   - 员工签字确认（拒绝签字则记录在案并由见证人签字）

3. **证人取证**（如适用）
   - 分别约谈相关证人
   - 书面证言 + 身份证复印件 + 签字

### Phase 2：处罚适配评估

使用 [case-assessment.md](case-assessment.md) 中的"处罚适配评估矩阵"，逐项打分：

**关键判断点：**
- 违纪金额 < 5,000元 且初犯 → **不建议直接红线解除**
- 无主观恶意 + 无实际损失 → **降级处理**（书面警告/记过）
- 制度本身规定模糊 → **不宜作为解除依据**

### Phase 3：程序合规核查

**逐项打勾，缺一不可：**

```
□ 规章制度经民主程序制定（职工代表大会/全体职工讨论）
□ 该制度已向员工公示/签收（有签收记录）
□ 违纪事实有充分、合法证据支撑
□ 处罚力度与违纪情节匹配（已过评估矩阵）
□ 已通知工会并获回复（违纪解除必须）
□ 员工不在法定保护期内（医疗期/孕期/工伤等）
□ 解除通知书已准备
□ 面谈时间地点已安排（工作时间内、私密空间）
□ 在场人员已确定（至少2人：HR + 业务主管）
```

**任一不通过 → 暂停，补正后再继续。**

### Phase 4：面谈执行

使用 [communication-templates.md](communication-templates.md) 中"场景A"的话术模板。

**面谈结构：**
1. 开场（2分钟）：说明目的，营造严肃但不对抗的氛围
2. 陈述事实（5-10分钟）：客观描述违纪行为，出示证据
3. 说明依据（3分钟）：引用具体制度条款
4. 告知决定（3分钟）：明确处分类型和生效时间
5. 倾听回应（10-15分钟）：让员工充分表达
6. 说明后续（5分钟）：交接安排、薪资结算、申诉渠道

### Phase 5：文书签署与归档

| 文书 | 要求 |
|------|------|
| 面谈记录 | 双方签字，拒绝签字则注明并由见证人签字 |
| 处分通知书/解除通知书 | 当面送达签收，或EMS邮寄（保留快递单） |
| 工会通知回执 | 工会签收记录 |
| 工作交接单 | 明确交接内容和完成时间 |

### Phase 6：后续跟进

- 工资结算：最后工作日结清，或下一个工资发放日
- 社保/公积金：缴纳至解除当月
- 离职证明：解除当日出具
- 系统更新：更新人事系统状态
- 风险跟踪：关注员工是否提起仲裁（时效1年）

## 特别提醒

> ⚠️ **基于败诉案例的教训：**
> - 推荐外购产品金额仅3,800元即做红线解除 → 被判处罚过重
> - 收受供应商200元礼金即做红线解除 → 被判管理问题败诉
> - **原则：处罚力度必须与违纪严重程度成正比，宁可处分不到位，不可处分过头。**
