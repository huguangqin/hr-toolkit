# 变化影响评估矩阵

每条捕获的法规变更，必须过一遍下面四维评估，才能决定"要不要改、改什么、多急"。不要凭一句话"这个新规很重要"就启动全员改制度——那会耗尽组织的改动耐心。

## 一、四维评估

| 维度 | 取值 | 含义 | 权重锚点 |
|---|---|---|---|
| **影响范围** | 广 / 中 / 窄 | 涉及多少 ER 场景（解除/绩效/调岗/工时/社保/个保…） | 广 = 多场景联动 |
| **紧迫性** | 高 / 中 / 低 | 生效日距今：≤60天=高；61–180天=中；>180天=低 | 高 = 先出速报 |
| **适配度** | 需改 / 微调 / 无需 | 当前制度/流程是否已覆盖该要求 | 需改 = 立项 |
| **违规成本** | 高 / 中 / 低 | 不改可能导致的处罚/败诉/赔偿量级 | 高 = 优先资源 |

### 综合判定规则

| 组合特征 | 结论 | 动作 |
|---|---|---|
| 影响范围=广 **且** 紧迫性=高 | 🔴 **高** | 3 个工作日内出速报，立即立项 |
| 影响范围=广 **或** 适配度=需改 **且** 违规成本=高 | 🔴 **高** | 当季闭环，指定责任人 |
| 影响范围=中 **且** 适配度=微调 | 🟠 **中** | 纳入下个制度修订窗口 |
| 影响范围=窄 **且** 适配度=无需 | 🟡 **低** | 记录备查，不下行动项 |
| 任何维度=草案未生效 | ⏸ **观察** | 标 `status=监测中`，生效前 60 天再评 |

**关键红线**：`紧迫性=高` 一律先出速报、再补细则，不允许"等研究透了再告诉业务"。

---

## 二、影响范围映射表（变更 → ER 场景）

拿到一条新规，先判断它戳中了哪些 ER 场景，再决定波及面：

| 变更类型 | 最可能影响的场景 |
|---|---|
| 解除条件/事由变化 | 违纪解除、过失性解除（联动 `er-case-communication` 场景 A） |
| 经济补偿/赔偿标准变化 | 协商解除补偿、2N 测算（联动 `er-risk-assessment` 敞口） |
| 绩效/不胜任认定口径 | PIP、调岗（场景 C/D） |
| 工时/加班/年休假 | 考勤制度、加班费欠付风险 |
| 社保/公积金 | 成本、历史补缴敞口 |
| 竞业限制/保密 | 离职管理、调查取证 |
| 个保/监控合规 | 违纪调查取证合法性（证据链评级降级风险） |
| 新就业形态认定 | 用工模式合规边界 |

---

## 三、行动项生成规则

评估完成后，按以下模板生成可执行动作（写入台账 `action_required` + `owner` + `deadline`）：

```
动作类型 | 触发条件 | 示例
制度修订 | 适配度=需改 | 《员工手册》第X条增补竞业限制补偿标准
流程卡点 | 影响范围含具体场景 | 解除前增加"个保合规告知"步骤
培训宣贯 | 影响范围=广 | 全员 ER 合规培训（重点：新解除事由）
系统配置 | 涉及计算规则 | 薪酬系统更新社平工资3倍封顶基数
个案复核 | 影响现有在办案件 | 复查3起进行中违纪解除的证据链
```

### 行动项要素（缺一不可）

1. **做什么**（具体到条款/步骤，不写"关注""研究"）
2. **谁负责**（人名或角色，禁止"相关部门"）
3. **截止日**（基于紧迫性推导，高紧迫 ≤ 生效前 30 天）
4. **验收标准**（如"新制度过民主程序并公示签收"）

---

## 四、追溯影响检查（联动在办案件）

重大变更（🔴）必须额外回答：**它会不会让"已经按旧规处置的案件"变成隐患？**

- 影响解除事由 → 复查 `er-case-analysis` 台账中"证据链 B/C 级 + 已结案未挑战"的案件
- 影响赔偿标准 → 复查进行中协商解除的补偿测算是否偏低
- 影响取证合法性 → 复查电子证据保全 SOP 是否仍合规

发现追溯敞口，单独成条写入速报"历史案件追溯"段落。
