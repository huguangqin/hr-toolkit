# 监控框架：对象分类 + 信息源目录 + 频率

## 一、8 类监控对象（分类树）

| 类别代码 | 类别 | 典型内容 | 对 ER 的影响面 |
|---|---|---|---|
| `L1` | 国家法律/行政法规 | 劳动合同法、社会保险法、劳动争议调解仲裁法修订 | 全局性、根本性 |
| `L2` | 司法解释 / 指导案例 | 最高法劳动争议司法解释、指导性案例 | 裁判口径，直接影响败诉率 |
| `L3` | 部委规章/规范性文件 | 人社部关于工时、年休假、竞业限制的规定 | 中观，常触发制度修订 |
| `L4` | 地方性法规/审判纪要 | 京/沪/粤高院审理纪要、仲裁委口径 | 地域性强，必须分城标注 |
| `L5` | 社保/公积金政策 | 缴费基数上下限、缓缴、补缴追溯期 | 成本测算、合规风险 |
| `L6` | 新就业形态/平台用工 | 外卖、直播等灵活就业劳动关系认定 | 用工模式合规边界 |
| `L7` | 个人信息/数据合规 | 员工信息处理、背景调查、监控合规 | 调查取证合法性 |
| `L8` | 行业监管 | 金融、医疗、教育等行业的用工特别规定 | 特定行业用工红线 |

**分类规则**：一条变更可能涉及多类时，按"最高影响层级"归主类，其余在 `affected_scenarios` 中说明。草案/征求意见稿归入同类但 `status=监测中` 且标题标注"（草案）"。

## 二、信息源目录（按层级）

### 国家级（月度巡检）

| 来源 | 关注点 | 入口特征 |
|---|---|---|
| 全国人大网 / 国务院 | 法律、行政法规立改废 | `npc.gov.cn` / `gov.cn` |
| 人社部官网 | 规章、规范性文件、政策解读 | `mohrss.gov.cn` |
| 最高人民法院 | 司法解释、指导案例、公报案例 | `court.gov.cn` |
| 国家医保局 / 住建部 | 医保、公积金 | `nhsa.gov.cn` / `mohurd.gov.cn` |

### 地方级（季度巡检，按公司布局城市）

| 来源 | 关注点 |
|---|---|
| 各省市人社厅（局） | 社保基数、仲裁口径、地方规定 |
| 各省市高级人民法院 | 劳动争议审理纪要、指导意见 |
| 各市劳动人事争议仲裁委 | 实操口径、裁量标准 |
| 地方公积金中心 | 缴存比例、缓缴政策 |

> 重点城市建议单列：北京、上海、广东（广州/深圳口径常有差异）、江苏、浙江——这些是多数企业用工集中地，也是裁判口径分化最明显的区域。

### 行业/第三方（每周扫一眼标题）

| 来源 | 用途 |
|---|---|
| 全国律协劳专委 / 主要律所劳动法评论 | 专业解读、趋势研判 |
| 威科先行 / 北大法宝 | 法规库检索、效力状态核对 |
| 主流财经/法律媒体 | 重大事件预警 |

## 三、监测频率与动作

| 频率 | 动作 | 产出 |
|---|---|---|
| 即时（突发事件） | 捕获 → 当天评估 → 标 🔴 | 单条速报 + 紧急动作项 |
| 月度（国家级） | 全量扫一遍国家级源 | 月度合规速报 |
| 季度（地方级） | 按布局城市扫地方源 | 季度地域补充速报 |
| 半年度 | 复盘监控盲区、更新源清单 | 监控机制优化备忘 |

## 四、监控有效性自检清单

- □ 是否覆盖了公司所有用工布局城市？
- □ 草案与生效条文是否分开标注？
- □ 每条变更是否关联到具体 ER 场景（而非泛泛"关注"）？
- □ 是否有人对 `status` 负责推进到闭环？
- □ 重大变更是否触发了 `er-case-communication` / `er-risk-assessment` 的复核？

> 监控的最大敌人是"收藏了但没动"。台账里 `监测中` 超过 90 天未推进的条目，必须要么评估落地、要么明确归档，禁止长期挂起。
