## 每张工具表的统一模板

模块/场景 · 工具名称 · 适用场景 · 操作步骤/方法 · 模板/话术（可直接复制）· 注意事项/常见坑 · 关联工具 · 版本与更新日期

## 如何使用

1. 直接浏览本仓库对应模块目录。
2. 复制需要的模板/清单，按贵司实际调整即可使用。
3. 关注版本号与「最后更新」日期，旧版本以 CHANGELOG 为准。

## 如何参与

欢迎 HR 同行一起把这张表做得更好：

- 提需求 / 纠错 / 建议新模块：开 [Issue](../../issues)
- 直接贡献内容：Fork 后提 PR，请遵循 [CONTRIBUTING.md](CONTRIBUTING.md) 与统一模板

## 更新节奏

- 双周：小更新（补一张表 / 修正一处）
- 季度：大版本（发公众号做阶段总结）
- 详见 [CHANGELOG.md](CHANGELOG.md)

## 内容分发草稿

公众号精编、知乎引流等"加工后内容"的草稿放在 [内容分发/](内容分发/)，便于复用 GitHub 母本、保持各平台口径一致。
